# 背景壁纸 · Background wallpaper

默认没有壁纸。打开 **设置 → 外观 → 背景壁纸**，可以选择随项目提供的内置图片，或把一张本机图片拖进壁纸区。也可以点「自选图片」。选择成功后才换背景；取消、格式不对、解码失败或浏览器存储失败时保留原来的设置。

自选图片支持 PNG、JPEG、WebP，最大 **20 MiB**。会检查真实文件签名并让浏览器实际解码，不接受 SVG、HTML、网址、目录或一次多张图片。拖放只在壁纸区生效，不接管其他模块的文件拖放。

「无壁纸」会关闭背景，但保留已经选中的图片；「启用已选图」可再打开。强度默认 **12%**，可调 **0–100%**。壁纸上始终保留当前亮暗主题的底色遮罩，正文、按钮和状态文字不设透明度。

自选图片和设置存在这台电脑、这个浏览器的 **IndexedDB** 中，按当前项目的根路径分别保存。它们不上传到后端或外网，不写进项目仓库，不进入新项目模板、存档或发布包。换一个项目默认仍没有壁纸；回到原项目会读取它自己的设置。清除网站数据、换浏览器或更换网站端口后可能需要重新选图。浏览器不能保存时，页面会提示，原图保持不变。

内置图片的目录是普通项目文件 `外观/壁纸/`，清单为 `清单.json`。进入外观时只读取小清单，默认不会读取壁纸图片；明确选择某张内置图片后才读取该项目里的图片，校验大小、SHA256、PNG 签名和解码结果。内置选择只把编号保存在浏览器，不把图片复制到浏览器数据库。当前编号从 **02** 开始，不补造 01。内置图片和本说明可以随新项目模板继承。

清单格式：

```json
{
  "version": 1,
  "wallpapers": [
    {
      "id": "02",
      "path": "外观/壁纸/02 白金世界树.png",
      "title": "白金世界树",
      "title_en": "Platinum world tree",
      "sha256": "填写这个文件真实的64位SHA256",
      "bytes": 1982636
    }
  ]
}
```

示例中的 SHA256 是说明占位文字，不能直接使用。实际清单必须写真实文件指纹。编号、路径不能重复；路径必须直接位于 `外观/壁纸/` 下且为 `.png`，不能是网址、转义路径或上级目录。可附 `source` 作为来源说明，程序不会打开来源里的原用户路径。修改清单后重新打开网页读取新清单。

## English

Wallpaper is **off by default**. Open **Settings → Appearance → Background wallpaper** to select a bundled image or choose one local PNG, JPEG or WebP image up to **20 MiB**. You may also drop one local image into the wallpaper area. Files are checked by their real signature and decoded by the browser. SVG, HTML, remote URLs, folders and multiple-file drops are rejected. Other modules retain their own file-drop behavior.

The previous wallpaper stays in place until validation and a browser storage transaction both succeed. Canceling, decoding errors or storage failure do not replace it. **No wallpaper** disables the background but keeps the selected image. **Enable selected image** restores it. Intensity defaults to **12%** and ranges from **0–100%**. The current theme's plane color remains over the image; text and buttons remain opaque.

Custom images and preferences are stored in this browser's **IndexedDB**, separately for each project root. They are not uploaded, written into the project, or included in new project templates, checkpoints or releases. A new project starts without wallpaper. Clearing site data, changing browsers or using another origin/port may require choosing the image again.

Bundled images are ordinary project files listed in `外观/壁纸/清单.json`. Settings reads the small manifest; PNG assets are only requested after an explicit selection, or when restoring that project's previously selected bundled image. The file's exact byte count, SHA256, PNG signature and decode result must match. Only the bundled image ID is stored in the browser. Source metadata is descriptive; original author paths are never opened. The bundled assets and this guide may be inherited by new project templates. No image numbered 01 has been invented.

全屏也沿用当前所选壁纸与0–100%强度；图片/视频/真实终端保留其原内容底色。Fullscreen views share the selected wallpaper and intensity; media and real terminals retain their own content backgrounds.
