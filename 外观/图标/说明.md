# 图标风格

设置 → 外观 → 图标。经典保留原来的图标和文字按钮；神话保留作者认可的想法、蓝图、戒律、工具、指令，并采用长卷轴计划；玉金是一组统一比例的线刻图标。选择存在玩家本机浏览器 `tpl_nav_icon_style`，与皮肤、金边、亮暗、字号独立。

本文件夹是普通 SVG symbol 素材，不依赖网络或安装。每个图标用 24×24 viewBox，currentColor 继承当前皮肤。玉金细节使用主题 accent。新增风格需在导航映射和设置选项中明确登记，不能直接执行文件内容。

经典中的图形来自本项目现有原创符号；神话、玉金为本项目原创绘制。图标只标识入口，不改变功能或权限。

作者确认：计划为长卷轴诗篇；源代码为球形科技反应堆；测试是正式通用模块，用电焊标识；技能为魔法五芒星阵。神话与玉金组均收录这些入口，经典仍可恢复旧样式。

笔记本入口（左边）用三本叠放的书；便签（右边）用羽毛笔和一页纸，两者功能独立。笔记本目录另有「笔记本日志」，读取已有笔记/日志/记录。禅读为抽象盘坐；亮暗为太阳/月亮；默认第一项「金玉线刻」，第二项「经典文字」，第三项「神话」。图形默认1.15rem大小/1.35细线，在设置外观内可调大小与线宽并恢复默认。首次皮肤默认玉色科技，已有手选保留。
