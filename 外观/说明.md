# 外观 · 自己做一套皮肤

在 **设置 → 外观** 里换。换的只是颜色、字、行距，三栏布局不动；选哪套记在这台电脑的浏览器里，不改项目。

- **黑白极简**（默认）：只有黑白灰，适合大多数人
- **暖色纸质**（自带）：奶油底、陶土色，10-01 以前的样子
- **精密深色**（自带）：近黑底、一点靛紫，行更密
- **玉色科技**（自带）：玉色操作、青铜金细节，保留系统字体，亮暗两档

## 自己做一套

1. 复制 `黑白极简.css`，改个名字，比如 `我的蓝.css`（文件名就是设置里显示的名字）
2. 改里面的值：`:root{…}` 是亮色，下面两份一样的是暗色（两份都要改）
3. 文件开头的注释里写一句「一句话：……」，设置里会显示
4. 打开 设置 → 外观，多了「我的蓝」，点一下就换

能改的变量：

| 变量 | 管什么 |
|---|---|
| `--plane` | 页面底 |
| `--card` | 卡片、顶栏、输入框 |
| `--fg` / `--fg2` | 正文 / 次要正文 |
| `--muted` | 灰小字（跟 `--card` 的对比至少 4.5:1，不然看不清） |
| `--line` / `--ring` | 分隔线 / 边框 |
| `--accent` | 主按钮、选中、链接 |
| `--onaccent` | 主按钮上的字（`--accent` 深就写白，浅就写黑） |
| `--lane2` | 第二栏的淡色块 |
| `--font` / `--mono` | 正文字体 / 等宽字体（编号、路径、代码） |
| `--lh` | 行高 |

规矩：
- **状态色不改**：好 · 不够 · 在做 · 缺 四种颜色固定，换皮肤也一样
- 只写变量，别改布局；想加别的样式也行，但布局变了算你自己的
- 想给别人用：把这个 .css 文件发给他，放进他应用的 `外观/` 文件夹

## 目录与按钮

设置→外观另有「分层金边 / 经典简洁」。它与皮肤和亮暗独立，选择立即全局生效并记在本机浏览器。金边皮肤变量--hover-gold（亮#a8853c、暗#d2b476）和--hover-gold-glow只管细节，不改状态色或主按钮字色。经典保留真实目录展开能力。
