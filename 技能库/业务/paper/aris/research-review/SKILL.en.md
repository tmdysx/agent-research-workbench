# Research Plan and Evidence Review

This is a local adaptation of pinned upstream methods. Follow the current goal, approved plan, and file scope; put actual materials/results in the author-selected workspace, not built-in folders.

## Inputs

Review question, current version, main claims, evidence, scope, and actual available reviewer.

## Workflow

1. Assemble a compact packet with problem, method, nearest work, main evidence, failures, and constraints rather than promotional summaries.
2. State whether this is self-check, human assessment, or an existing independent employee and record independence/provenance through actual permissions/tasks.
3. Assess problem anchoring, contribution distinction, experiment support, fairness, and counterevidence with locatable comments, separating fatal gaps, fixable issues, and suggestions.
4. Respond with linked new evidence, retaining review versions, replies, and changes for bounded iterations rather than timer-based duplicate reviews.
5. Summarize resolved/open issues for the authorized decision-maker; review scores do not replace platform delivery acceptance.

## Outputs

review-packet.md, review-findings.md, response-map.md, and review-history.md.

## Acceptance

- Criticism traces to material and independent review is distinguished from self-check.
- Missing external-review capability is marked unverified without invented jury/oracle verdicts.

## Continue When

Revise within authorized scope and return direction changes to the author; this entrypoint neither configures nor starts upstream reviewer MCP.

## Tools and Status

Bundled guidance does not prove installed dependencies or validated runtime. Reading/copying a skill does not enable automation, create employees, rent resources, or publish outputs.

## Review provenance and evidenced findings

1. Distinguish self-check, independent-worker same-model, cross-model and human review; inherited construction context is not zero-context review.
2. Each finding retains location, evidence, affected claim, severity, action, owner and closure evidence.
3. Scores grant no review permission and replace neither plan nor delivery acceptance; report unavailable independent roles.
