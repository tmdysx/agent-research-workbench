# 实验执行与失败记录

此入口是固定上游方法的本地适配。按当前目标、批准计划和修改范围做事；材料与结果写作者指定工作区，内置不保存真实业务材料。

## 输入

正式实验计划、合法输入、代码版本、获准运行环境、命令与停止条件。

## 步骤

1. 读取计划和实际环境记录，核代码/数据位置、运行器版本、CPU/GPU、空间与依赖；不因上游配置gpu:remote就获得远程授权。
2. 先最小输入或短步检查，确保输出目录独立、日志可写、指标有意义，再确定正式命令。
3. 按获准命令启动，记录PID或实际运行标识、开始时间、资源和版本；终端打开不等于训练成功。
4. 按预算看真实进度、异常和结束状态；需停止只操作本次明确标识的作业，保存部分产物和失败原因。
5. 检查产物可读、评价配置与原始日志一致，写可复跑命令与接手；未跑到的检查不写通过。

## 产物

环境记录、独立run目录、命令/日志/原始输出及run-report.md；代码同步、上传或通知不在默认范围。

## 验收

- 启动、结束与失败均有真实进程/日志证据。
- 原数据不覆盖，复跑需具备同版本与输入。

## 继续条件

实际输出足以分析后转结果；失败或缺环境交具体接手项，不自动租云或销毁实例。

## 工具与状态

- **实验自身运行环境**: 由当前获准实验确定，不默认安装PyTorch、W&B或Modal。

方法已收录不等于依赖已安装或运行已验收。阅读、复制技能不会启用自动化、创建员工、租资源或发布产物。

2. 记录代码/配置/数据版本、环境、完整命令、PID/开始结束/退出码、日志与原结果位置。
3. 六项核验：真值来源；指标分母；真实结果文件/键；评价代码真调用；样本种子配置范围；正文措辞不超证据。
