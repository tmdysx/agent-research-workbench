# Presentation contract and ownership

- Input mode: new generation / screenshot reconstruction / native-object edit / template work. Choose explicitly and save separate output.
- Lock brand/facts: fonts, colors, marks, terms, data, citations and asset rights. Flexible: layout, grouping, spacing and emphasis.
- Per-slide contract: reader job, core message, evidence/figure, layout, notes, timing and checks.
- Canonical ownership: content/data, chart sources, asset provenance, editable objects and exports each have owner/version.
- Repair at the owning layer: content errors in content, native-object errors in generation/editing, export errors in export; recheck affected slides.
