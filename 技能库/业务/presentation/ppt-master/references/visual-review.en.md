# Actual visual and file checks

- Actually render every page and retain previews; object coordinates alone do not establish readability or quality.
- Check overflow/overlap, fonts, spacing, crop, alignment, image resolution, labels, arrows and contrast.
- Check chart numbers, units and legends against source data/prose; decoration is not evidence.
- Open the PPTX and target export, checking editability, notes, page order and media. Good renders do not prove the final file opens.
- Measure rehearsal time and report findings/before-after changes; unperformed opening/timing remains unverified.
