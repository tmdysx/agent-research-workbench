# 路线与阶段
方法研究走设计、基线、主实验、分析和写作；复现研究可以把条件差异和负结果作为结论；综述走检索筛选提取综合，不捏造训练；理论走定义、证明义务与反例，不以随机实验替代证明。

| 阶段 | 人应看到的东西 | 进入下一步依据 |
|---|---|---|
| 选题 | 问题假设近似研究 | 可检验且资源可用 |
| 文献 | 查询记录证据定位限制 | 范围缺口有据 |
| 设计 | 数据许可划分比较预算 | 公平有效评价 |
| 运行 | 版本命令日志真结果 | 评价检查通过 |
| 分析 | 可复算图表和有界论断 | 支持关系明确 |
| 写作 | 稿件引用数值声明 | 证据与待核透明 |
| 投稿 | 官方对照本地包 | 作者检查决定 |
| 返修 | 意见修改证据位置 | 逐条回应 |

已有模块优先承接；选题/投稿独立模块为用户选用的业务配置，不写死后端。
施工状态与来源核验、评价有效、结论支持、作者确认分开。平台交付不是论文录用。
