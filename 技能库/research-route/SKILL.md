# 科研路线

任何能读取 Markdown 的 agent 都可按本技能执行，无需本平台另接模型 API。模板复制到授权业务目录后填写，原始证据保留。本包以计算与机器学习科研为主；综述/理论按证据类型调整，不能凭此包执行真实临床/动物/湿实验。

## 输入

人的原话、获准目标与计划、最新交接、授权范围内已有产物清单、期限和资源。未知项写未确定，不扫描私人论文库补答案。

## 操作

1. 本项目先读 AGENTS.md、接手技能和适用模块戒律，沿用既有需求来源与编号。读 [references/路线与阶段.md](references/路线与阶段.md)，用真实产物判断当前阶段；文件写完与科学结论成立分开记录。
2. 用 [assets/路线卡.md](assets/路线卡.md) 记阶段、依赖、产物路径、验收和缺口。复现、方法研究、综述、理论走不同分支；跳过阶段说明替代产物。
3. 排当前能做的第一件事，写总时长、运行次数、单次资源、费用上限、失败重试及停止条件。缺预算时先整理文件、设计和公开文献，不启动长实验。
4. 每次只读相关阶段技能，执行授权工作并检查真实产物，按项目记录交付/交接；不由技能启动其他 agent 或平台模型 API。受阻只暂停依赖它的工作。
5. 预算用尽、重复失败到上限或用户叫停时结束该工作项，保存证据和建议。不得为负结果擅自修改目标、删记录或绕过验收。

## 产物

科研路线卡、当前阶段的开工计划、已有产物/缺口清单与交接。业务材料按既有文献、实验、论文、汇报、素材模块承接；机器记录不写进人的笔记。

## 验收

人不用读代码就能指出现在在哪、判断依据、下一件事和怎么验。每一项已验状态可打开真实产物；未运行、待核和缺输入没有标完成。换 agent 能沿同一路线接手。

## 缺口与停止条件

数据权限、科学判断、资源或投稿授权未定时记具体缺口。付费、公开上传、正式投稿不因路线卡而获授权。施工验收与来源核验/结论支持/作者确认分别留状态。

## 下一步

研究问题未明确先读“选题与假设”；否则读取当前有输入的阶段。不要一次加载全部技能。
