# 投稿准备

任何能读取 Markdown 的 agent 都可按本技能执行，无需本平台另接模型 API。模板复制到授权业务目录后填写，原始证据保留。本包以计算与机器学习科研为主；综述/理论按证据类型调整，不能凭此包执行真实临床/动物/湿实验。

## 输入

目标期刊/会议、文章类型、最新版稿、图表附件、引用核验与真实作者信息。目标未定先列通用清单，不自行选期刊假装完成投稿包。

## 操作

1. 核当期官方作者指南和适用轮次，记 URL/访问日；查篇幅、匿名、文件格式、引用、附件、报告规范和 AI 政策。经验不当现行规则。
2. 用 [assets/投稿清单.md](assets/投稿清单.md) 对照材料。报告规范按实际学科设计，不把医学模板套到所有论文。
3. 建独立本地包保留源稿；仅需要匿名时建匿名副本，核名字、致谢、链接、属性和附件；原稿历史不删。
4. 据真记录准备附信、贡献、冲突、经费、伦理、数据代码和 AI 使用草稿；身份、推荐审稿人与理由不可编，未知留作者确认。
5. 实际打开/渲染，核图表清晰、正文附件一致、证据及引用状态；留最终文件版本与指纹清单。
6. 分清本地包齐全、待作者确认和缺文件。本阶段不登录、付款、上传、发送邮件、正式提交或公开发布；技能名字不授权外部动作。

## 产物

本地投稿包、官方要求/日期对照、附信与声明草稿、作者待确认/缺口和版本清单。

## 验收

人打开最终稿与附件，逐项看到官方要求及真实检查。格式、未核与作者确认分开；准备好不写已投稿或会录用。

## 缺口与停止条件

目标、身份、证据或必要材料未齐标未就绪，继续本地整理。政策冲突具体待判断；无自动提交脚本和主动连接。

## 下一步

交作者与其明确授权的投稿操作者；作者反馈回写作，审稿意见到来再返修，保留各版。
