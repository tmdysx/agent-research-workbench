# 网页前端

一套已经跑通、逐条验过的网页定式。**起手复制 `参考/模板.html` 再改**，比从零想快，还能避开下面这批坑。
**项目根有 `DESIGN.md` 的，先读它**：那是这个项目定下来的样子（布局、颜色、组件、要这样 / 不要），跟这里不一样时以它为准；这份技能只讲通用做法和坑。
（参考文件连着「自动化科研交互界面」的后端才有数据；只拿来看结构和样式也行。）

## 一、骨架

```
┌ nav（sticky，本身不能有 overflow）────────────────────────────┐
│ ① 通用   项目名 · 总览 · 外部资料入口 · 全站检索   [工具条钉右] │
│ ② 业务载荷  项目自己的模块（只有这一条能加）                    │
│ ③ 通用   存档 · 清理 · 违规 · 待办 · 设置 · 技能 · 快捷指令 · 使用说明 │
└──────────────────────────────────────────────────────────────┘
┌ 左栏 ┬ 正文 ─────────────────────────────────────────────────┐
│ 目录 │ 总览：计数、模块表、待你判断、蓝图                        │
│ 决定 │ 模块页：左栏换成目录（名字/大小/时间），正文是预览          │
└──────┴──────────────────────────────────────────────────────┘
                                         浮动笔记窗（可拖可缩）
```

- **中间那条只放项目自己的东西**。工具自带的部件（外部资料入口、技能、快捷指令、使用说明）放第一或第三条
- 一个页面 = `body` 上一个 `data-view`；地址用 `#/`、`#/m/模块名`、`#/inbox` 这类，刷新还在原处

## 二、六条 CSS 铁律（全是撞出来的，别简化）

1. `white-space:nowrap` 加在**链接**上——不加，中文被逐字折成竖排
2. `flex-wrap:nowrap` + `overflow-x:auto` 放在**每条导航**上，不放 nav 上
3. **sticky 和 overflow 不能同层**：nav 负责 sticky，里面每条负责横滚
4. 别给 `html/body` 写 `height:100%`，用 `min-height`——否则滚过一屏顶栏就脱手
5. **工具条在横滚那条的外面**（绝对定位钉右），导航留出 `--toolsw` 的空位
6. 顶栏高度、工具条宽度**用 JS 量出来**写进 `--navh` / `--toolsw`；只挂 ResizeObserver 不够，再挂 resize、load、fonts.ready，工具条自己也要单独盯

## 三、字号与配色

- `html{font-size:calc(clamp(13.5px, .32vw + 12.3px, 17px) * var(--fs,1))}`，其余一律 `rem`；A- / A+ 两个按钮调 `--fs`（0.8–1.4）
- 暖调：底 `#f0eee6` · 卡片 `#faf9f5` · 字 `#141413` · 次字 `#6e6c63`（对比度 ≥4.5）· 强调陶土色 `#ad5132`；暗色同时写 `prefers-color-scheme` 和 `[data-theme=dark]` 两份
- **风格只要两档：亮 ↔ 暗**，点一下换一下；第一次打开跟系统
- 状态色固定：好 `#0ca30c` · 不够 `#fab219` · 在做 `#ec835a` · 缺 `#d03b3b`；**只用小色点 + 文字，不用图标**

## 四、标签

- **不用 emoji 图标**。一律「中文 <span class=en>English</span>」，英文灰色小一号：`总览 Overview`、`文献 Literature`
- 人明确要求图标时，按项目 `DESIGN.md` 使用简洁 SVG，保留文字标签。MiracleHarness2 本次已获作者授权；图标不能替代状态文字，也不使用别家品牌图标。
- 当前项：下划线或左边框 + 底色

## 五、预览嵌进页面，不套框

- md 直接排成正文；代码、文字用等宽字体排在页面里；**不要**带边框的内滚动框
- 网页文件：iframe 不要边框，**高度撑到跟内容一样**——服务器给嵌入版末尾加一段脚本，把 `scrollHeight` 用 `postMessage` 报给外面，外面设高度。滚的是整个网页的滚动条
- **隔离靠服务器发的 `Content-Security-Policy: sandbox allow-scripts …` 头，不要再给 iframe 加 `sandbox` 属性**——两个叠在一起，嵌入脚本跑不起来（实测）
- 文件名那一行 `position:sticky` 贴在导航下面，放「收起目录 / 写进笔记 / 新标签打开」

## 六、笔记 = 给 agent 的指令

- 浮动窗：拖标题移动、右下角拉大小、双击归位；**限位把整个窗口留在屏内**
- 导出时自动拼：项目现状 · 这次看过的文件 · 点过什么 · 拍过什么板 · 我的判断 · 约束
- 页面上的动作（看文件、分拣、拍板）边做边记，导出时一并带上

## 七、网页不删任何东西

- × 只往笔记里写一句删除指令，交给 agent（先存档，再挪进回收站）
- 连着后端时，所有写操作都记「谁做的」

## 八、只做电脑

不写响应式断点，不测窄屏；窄屏溢出几像素不是 bug。

## 九、交付前自查

| 查什么 | 怎么查 |
|---|---|
| 数字对不对 | 说三栏就数页面上是不是 3 行 |
| 顶栏钉住 | 滚到 2000px，`nav.getBoundingClientRect().top` 为 0 |
| 中文不竖排 | 导航里每个链接高度不超过一行 |
| 变量不过期 | `--navh` / `--toolsw` 跟实测宽高一致（预览窗隐藏时浏览器会暂停刷新，量出来不准不算 bug） |
| 图标符合授权 | 页面里没有 emoji；SVG 保留文字标签，符合人的要求和项目 DESIGN.md |

## 常见错误

- 工具条放进横滚那条里 → 被推出视野
- `html,body{height:100%}` → sticky 失效
- 正则删 CSS 规则留下悬空选择器 → 吞掉下一条规则，改完数一遍花括号
- favicon 用 `data:image/svg+xml` 时 `<` `>` 要写成 `%3C` `%3E`，不然截断到半截会在页面左上角冒出乱码
- 只改了网址 `#` 后面的部分不会重新加载页面：验新代码要真的刷新
