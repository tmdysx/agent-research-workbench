# PPT预览

> 插件：不进核心代码，玩家自己装、自己启用（总蓝图 S1-11「玩家自己组装」）。拿掉这个文件夹，核心照常，PPT 退回只列字和图。

## 它做什么

网页里点开一份 PPT，核心只能列出每页的标题、文字、图片（网页画不出 PPT 的版面）。装了这个插件：后台用本机的 **PowerPoint**（或 **LibreOffice**）**只读**打开这份 PPT，转成 PDF，网页里照原版一页页翻。

- 转出来的 PDF 放 `索引/预览缓存/`（能删能重建，不进模块、不进 git）；原 PPT 一个字节不改
- 同一份没改过就不重转；第一次几秒（9 页的 PPT 实测 4.5 秒）
- 你本来开着 PowerPoint 的，转完不会把它关掉

## 要的外部程序（有一个就行）

| 程序 | 怎么知道有没有 | 许可 |
|---|---|---|
| Microsoft PowerPoint（Office 2016 及以后，Windows） | `检查.ps1` 查 PowerPoint 能不能被调用 | 你自己的 Office |
| LibreOffice（免费，Windows / Mac / Linux） | `检查.ps1` 找 `soffice` | MPL-2.0 |

## 安装（写给 agent：照着做，**装之前先问人**，说清装什么、多大、从哪来）

1. 先跑检查：在这个文件夹里 `powershell -NoProfile -ExecutionPolicy Bypass -File 检查.ps1`——输出「用 PowerPoint」或「用 LibreOffice」就是已经有了，**不用装**，直接到第 3 步
2. 都没有：装 LibreOffice（约 350 MB，官方：https://www.libreoffice.org）
   - Windows：`winget install --id TheDocumentFoundation.LibreOffice -e`
   - Mac：`brew install --cask libreoffice`
   - 装完再跑一遍检查
3. 启用：人在网页上点开一份 PPT，点「用 PPT预览 插件显示原版」（第一次会问一句）——**启用是人点的，agent 不替人启用**

## 怎么调（给 agent 和核心看）

- 检查：`检查.ps1`，退出码 0 = 能用，输出用的是哪个
- 转换：`转换.ps1 -In <PPT 的完整路径> -Out <PDF 的完整路径>`，退出码 0 且 PDF 在 = 成功；超过 180 秒算失败

## 守的规矩

- 只读打开，不改、不另存原文件；只写 `-Out` 给的那一个 PDF
- 不联网；不弹窗口
