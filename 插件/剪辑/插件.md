# 剪辑

> 插件：不进核心代码，玩家自己装、自己启用（总蓝图 S1-11「玩家自己组装」）。拿掉这个文件夹，核心照常：视频照样能在网页里放，只是不能剪。
>
> 这一版只有说明。网页上的「用 剪辑 打开」（S1-11 S2-4）和剪辑页面（S2-6）还没做；现在 agent 照下面「给 agent 怎么调」直接跑 ffmpeg 命令剪。

## 它做什么

用本机的 **ffmpeg**（命令行的视频处理程序）剪视频：

- **截段**：从一段视频里截出第几秒到第几秒
- **拼接**：把几段按顺序接成一段
- **去声**：去掉声音，只留画面
- **截图**：把某一秒的画面存成图片
- **字幕**：把字幕文件（.srt）烧进画面（烧进去以后哪个播放器都看得到）
- **画面上加字和框**：在第几秒到第几秒，在画面某个位置加一句话、画一个框
- **剪辑单**：每个成品旁边留一份文字记录，写清怎么剪出来的；要改就改剪辑单、照它重剪

剪出来的放 `资料/素材/剪辑/`（网页上就是「素材」模块里的「剪辑」文件夹）。**原视频只读，一个字节不改。**

## 开头那几行为什么这样填

- **检查**：`ffmpeg -version`，只看版本。后台在插件文件夹里跑这一条，退出码 0（正常结束）= 这台电脑有 ffmpeg。
- **转成、转换两格空着**：后台把「管这种文件 + 转成 pdf + 有转换命令」的插件当成**预览工具**（「PPT预览」就是这样：打开 PPT 时转成 PDF 给网页看）。剪辑不是预览，这两格填了，网页打开 mp4 时会拿它去转。
- **管哪些文件**：列的是剪辑能接的视频种类。等 S2-4 做好，这几种文件上出现「用 剪辑 打开」。现在因为「转成」空着，列了也不会被当成预览。

## 要的外部程序

| 程序 | 怎么知道有没有 | 装在哪 | 许可 |
|---|---|---|---|
| ffmpeg（同一套里带 ffprobe，用来看视频多长） | `ffmpeg -version`，退出码 0 就是有 | 装在系统里，不放进插件文件夹、不进项目。装好后看实际位置：Windows 用 `where ffmpeg`，Mac 用 `which ffmpeg` | GPL（详见下面「许可」） |

- 版本：不挑。官方下载页 2026-10-01 写的最新稳定版是 9.0.2（2026-09-18 发布）
- 还要 ffmpeg 里带两样东西：字幕要 **libass**（`subtitles` 滤镜（ffmpeg 里处理画面的一个步骤）），画面上加字要 **libfreetype**（`drawtext` 滤镜）。下面推荐的装法都带这两样；装完照「装完怎么验」第 2 步查

## 安装（写给 agent：照着做，**装之前先问人**，说清装什么、多大、从哪来、什么许可）

1. **先跑检查**：`ffmpeg -version`。有输出、退出码 0，再照「装完怎么验」第 2 步查字幕和加字的功能；都有就**不用装**，直接到第 5 步
2. **问人**：把下面这几样告诉人，人点头再装——装 ffmpeg（视频处理程序）· 从哪来（下面写的网址）· 多大 · 许可 GPLv3 · 装在系统里，拿掉插件也不会自动卸载
3. **Windows**
   - ffmpeg 官方只发源代码，不发 Windows 安装包；官方下载页（https://ffmpeg.org/download.html）的 Windows 一栏列了两家现成的：gyan.dev（https://www.gyan.dev/ffmpeg/builds/）和 BtbN（https://github.com/BtbN/FFmpeg-Builds/releases）
   - 用 gyan.dev 的 essentials（常用）版，命令照它页面上写的：`winget install "FFmpeg (Essentials Build)"`
   - 同一页还写了：`choco install ffmpeg`、`scoop install ffmpeg-essentials`——电脑上有 Chocolatey 或 Scoop 的也可以用
   - 多大：gyan.dev 页面写 essentials 版压缩包 7z 格式 34 MB、zip 格式 109 MB（2026-10-01 看）；winget 实际下的是哪一个、装好占多大**没查到**，以下载时显示的为准
   - 第一次用 winget 可能要同意来源条款：让人自己点，agent 不替人同意
   - 装完要**新开一个终端**才找得到 ffmpeg；这个工具的后台也要关掉重开（关掉再双击 `启动.bat`），因为后台是装之前开的，不知道新加的路径（这一条是照后台的代码推的，没在本机试过）
4. **Mac**
   - 官方下载页的 macOS 一栏列的是 evermeet.cx（https://evermeet.cx/ffmpeg/）的现成版；用 Homebrew（Mac 上的命令行装软件工具）更省事
   - 用：`brew install ffmpeg-full`。不用普通的 `brew install ffmpeg`：Homebrew 网站 2026-10-01 列的普通 `ffmpeg` 依赖里没有 libass 和 freetype，字幕和加字可能用不了；`ffmpeg-full` 里有
   - `ffmpeg-full` 装好后 Homebrew 不会自动把它放进命令行找得到的地方（Homebrew 叫 keg-only），要加一行再新开终端：`echo 'export PATH="$(brew --prefix ffmpeg-full)/bin:$PATH"' >> ~/.zshrc`。改 `~/.zshrc`（终端的设置文件）也先跟人说
   - 多大：**没查到**。Homebrew 网站列的 `ffmpeg-full` 直接依赖有 47 个库，第一次装要下不少东西，以 Homebrew 下载时显示的为准
   - 不用 Homebrew 的：从 evermeet.cx 下 ffmpeg 和 ffprobe 两个文件，解压后放进命令行找得到的文件夹（这条没在本机试过）
5. **装完怎么验**
   1. `ffmpeg -version`：第一行是 `ffmpeg version ……`，退出码 0
   2. 查字幕、加字、加框这三样在不在：Windows `ffmpeg -hide_banner -filters | findstr "subtitles drawtext drawbox"`；Mac `ffmpeg -hide_banner -filters | grep -E "subtitles|drawtext|drawbox"`——三行都要有
   3. 拿一段短视频照下面「截图」那条跑一次，`索引/剪辑临时/` 里出现一张图片就算通了（试完把这张图挪进回收站）
   4. 记下来：装了什么、哪个版本、从哪来，写进日志；在 `工具库/` 给 ffmpeg 写一张工具卡（通-15）
6. **启用**：S2-4 做好以后，人在网页上点「用 剪辑 打开」——**启用只由人点，agent 不替人启用**

## 许可

- ffmpeg 本身：大部分代码是 LGPL 2.1 或更新的版本；有些可选部分是 GPL 2 或更新的版本，编译时用了这些部分，整个 ffmpeg 就按 GPL。所以同一个 ffmpeg 有「LGPL 构建」和「GPL 构建」两种，看编译时开没开这些部分（出处：https://ffmpeg.org/legal.html）
- 上面推荐的几种现成版都是 **GPL 构建**：gyan.dev 页面写明它的版本都是 GPLv3；Homebrew 的 `ffmpeg`、`ffmpeg-full` 写的是 GPL-3.0-or-later；evermeet.cx 页面列的编译参数里有 `--enable-gpl --enable-version3`（即 GPLv3）
- 跟这个项目的关系：插件只调用人自己装在本机的 ffmpeg，ffmpeg 不打包进项目、不随项目发。以后要不要打包进项目由人定，打包前先读 legal.html

## 管哪些文件

- **能剪的**：.mp4 .mov .mkv .webm .avi .m4v（ffmpeg 认得的还更多，这几种最常见）
- **只读的**：原视频、字幕文件（.srt，UTF-8 编码）、要加到画面上的字（.txt，UTF-8 编码）
- **只写两处**：
  - `索引/剪辑临时/`：中间文件（截出来等着拼的片段、拼接清单）和还没跑完的输出，能删能重建，不进模块、不进 git
  - `资料/素材/剪辑/`：成品视频（.mp4）、截图（.png）、剪辑单（`<成品名>.剪辑单.md`）

## 给 agent 怎么调

先说三条通用的：

- **先写到临时文件夹，跑成功再挪**：每条命令都输出到 `索引/剪辑临时/`；退出码 0、文件在，再挪进 `资料/素材/剪辑/`。失败的半成品不进素材
- **每条命令都带 `-n`**：同名文件已经有了就停下，不覆盖；换个名字（加序号，如 `成品-2.mp4`）再跑。不用 `-y`（会直接覆盖）
- **导出参数**：要在浏览器里能直接放，导出成 H.264 画面 + AAC 声音的 mp4。下面表里写「导出参数」的地方，换成：
  `-c:v libx264 -crf 20 -preset veryfast -pix_fmt yuv420p -c:a aac -movflags +faststart`

| 要做的 | 命令（例子） | 说明 |
|---|---|---|
| 看多长 | `ffprobe -v error -show_entries format=duration -of csv=p=0 "原视频.mp4"` | 输出秒数 |
| 截段 | `ffmpeg -n -ss 00:01:05 -i "原视频.mp4" -t 15 导出参数 "片段1.mp4"` | 从 1 分 05 秒起截 15 秒。重新编码，切点准；改用 `-c copy` 快很多，但只能切在关键帧上，切点会偏几秒 |
| 拼接 | 先写 `清单.txt`，一段一行：`file '片段1.mp4'`；再跑 `ffmpeg -n -f concat -safe 0 -i 清单.txt -c copy "成品.mp4"` | 清单和片段放同一个文件夹。几段要是用同一套导出参数截出来的，才能这样直接拼 |
| 去声 | `ffmpeg -n -i "片段.mp4" -c:v copy -an "无声.mp4"` | 画面不重新编码，很快 |
| 截图 | `ffmpeg -n -ss 00:00:10 -i "原视频.mp4" -frames:v 1 "截图.png"` | 第 10 秒那一帧 |
| 字幕 | `ffmpeg -n -i "片段.mp4" -vf "subtitles=字幕.srt:force_style='FontName=Microsoft YaHei'" 导出参数 "带字幕.mp4"` | 在字幕文件所在的文件夹里跑，只写文件名：Windows 路径里盘符的冒号在滤镜里要另外转义，容易出错。Mac 上字体名换成 `PingFang SC` |
| 加字 | `ffmpeg -n -i "片段.mp4" -vf "drawtext=fontfile='C\:/Windows/Fonts/msyh.ttc':textfile=字.txt:x=40:y=40:fontsize=36:fontcolor=white:box=1:boxcolor=black@0.5:enable='between(t,2,6)'" 导出参数 "加字.mp4"` | 字写进 `字.txt`，躲开命令行里中文和标点的转义。字体文件：Windows 用微软雅黑（盘符后的冒号前要加 `\`）；Mac 换成本机一个中文字体文件的路径（「字体册」里右键「在访达中显示」能看到）。`enable` 写第几秒到第几秒显示，`x`、`y` 是字的左上角 |
| 加框 | `ffmpeg -n -i "片段.mp4" -vf "drawbox=x=100:y=80:w=320:h=180:color=red@0.8:t=4:enable='between(t,2,6)'" 导出参数 "加框.mp4"` | `x`、`y` 是框的左上角，`w`、`h` 是宽高（像素），`t` 是线多粗 |
| 字和框一起 | 用逗号连进同一个 `-vf`：`-vf "drawbox=……,drawtext=……"` | 一次编码，画质少损失一次 |

**剪辑单**（每个成品一份，跟成品放在一起：`资料/素材/剪辑/<成品名>.剪辑单.md`）写清：

- 原视频（路径）· 截哪几段（起止时间）· 拼的顺序 · 去不去声
- 字幕文件 · 加的字和框（第几秒到第几秒、位置、内容）
- 导出参数 · 实际跑的每一条命令 · 哪天剪的、谁剪的

要改：改剪辑单，照它重跑一遍，导出成新文件（加序号），旧的不覆盖。剪辑单的具体格式先这样，S2-6 做剪辑页面时再定。

## 守的规矩

- **原视频只读**：不改、不覆盖、不在原来的位置另存；输入和输出不能是同一个文件
- **不覆盖**：命令都带 `-n`；同名就换名字
- **只写两处**：`索引/剪辑临时/` 和 `资料/素材/剪辑/`，别的地方不写
- **装之前先问人**（S1-11 守的规矩）：说清装什么、多大、从哪来、什么许可；只从 ffmpeg 官方下载页列出的来源装；装了记日志、写工具卡
- **启用只由人点**，agent 不替人启用
- 剪的时候不联网、不上传、不弹窗口
- 一次只跑一个 ffmpeg（同时跑几个电脑会很卡）
- 不进核心代码：拿掉 `插件/剪辑/`，核心照常

## 这一版还没有的
