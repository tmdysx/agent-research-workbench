# MiracleHarness2

![MiracleHarness2](品牌/miracleharness2-hero.png)

A local web console, Python backend and optional MCP interface for long-running projects. People set direction; their chosen agents do the work. Goals, requirements, plans and deliveries remain ordinary local files.

## Start

Install Python 3.12 from [python.org](https://www.python.org/downloads/), open PowerShell in this folder and run `python -m pip install -r backend/requirements.txt`. Double-click `启动.bat`, fill in your own goals and ask your agent to read `AGENTS.md`. Create another project through Settings or `新项目.bat`. Staff execution and plugins are disabled by default.

## Included examples

This is one complete distribution, including shared governance, research worksheets, declared method packages and demonstration payloads for presentations, literature reading, novel writing, paper writing, ideas and promotional videos. They are examples and reusable templates, not the user's actual research or business results. Declared examples continue into new projects.

The introduction PPT/PDF has 23 pages. Original pages 1–22, including the original contact page, remain intact; page 23 explains noncommercial use and commercial licensing. The retained promotional video is a historical demonstration; an old website shown in a video is part of that example. Audio licensing has not been independently verified. Optional method links that are not bundled are labeled accordingly.

Only original project illustrations and official text links are retained for tools. Third-party screenshots and original logos are excluded. A fresh index contains only the public starter examples; the source project's database, personal notes, logs, machine settings and archives are excluded. External programs such as Office, LibreOffice, Git and FFmpeg must be obtained separately when needed.
