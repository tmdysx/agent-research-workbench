# 论文工作台

按引言、相关工作、方法、实验、超参数、应用、结果、未来展望、参考文献九个章节组织当前文稿。章节顺序、名称和目录可编辑；无关章节可以移除，普通项目可改成项目文书。

点新建将模板复制到正文目录，随后编辑、保存。摘要、结论和项目文书是可选模板，不自动生成。既有稿件继续在原位置，通过文件目录打开。模板本身只读，不放真实研究资料。

正文和配置都使用普通文件。网页和 agent 读写同一份记录；保存前核对版本，冲突时保留输入，修改旧稿前保存历史。新项目只继承内置模板，不带当前项目正文、数据、笔记和运行记录。
