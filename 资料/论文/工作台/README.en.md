# 论文 workspace

Organize a draft using Introduction, Related work, Method, Experiments, Hyperparameters, Application, Results, Future outlook and References. Edit names, ordering and folders; remove irrelevant sections or use project-document headings.

Create a document by copying a template into a working folder, then edit and save. Abstract, Conclusion and Project document are optional templates. Existing manuscripts stay in place and are accessible through the file tree. Templates are read-only and contain no real research materials.

Documents and configuration are ordinary files shared by the webpage and agents. Saving checks the source revision; conflicts retain your input, and updates preserve the previous file in history. New projects inherit built-in templates rather than working drafts, datasets, notes or run records.
