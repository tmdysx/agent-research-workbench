# 真实结果比较与解释

本入口是中文方法适配；英文入口与它等义，二者均不是上游全文直译。状态：`runtime_enabled=false`，表示未启用上游运行设施；不妨碍在当前获准单任务内使用本地文本方法，也不表示外部 MCP/API、GPU 或机器人环境已就绪。只读写当前任务明确范围，不继承上游自动权限、固定模型或无限 review；不自动上传、发通知、定时、租 GPU 或扫描作者 home。实际证据、独立审查和未验证状态分别记录。

## 输入

获准读取的 JSON/CSV/日志结果、各配置与基线的定义、指标方向、种子或重复运行信息。

## 方法

1. 按运行和配置读取真实结果，核对指标单位、样本口径、数据划分与缺失项；失败或未完成的运行单独保留。
2. 以模型、超参数和数据设置作为自变量，列主指标与辅助指标；计算相对基线的变化并说明分母，基线为零或口径不同时不硬算相对提升。
3. 有多种子或重复运行才报告相应均值与标准差，保留实际重复数；参数扫描识别单调、U 形、平台等趋势，标出离群结果。
4. 对每个发现分别写观察、可能解释、对研究问题的含义与可检验的下一步；相关趋势不直接升级为因果机制。
5. 把重要发现关联到结果文件与版本，提出报告更新；没有实际运行或缺少关键比较时，结论保持未定。

## 产物与验收

带来源的比较表、实际重复统计、异常清单、观察—解释—验证建议；验收应能从原始结果复算关键数字，且不会把失败项当零值或成功项。

## 依赖与边界

正文没有必须的 MCP、模型 API、云 GPU 或定时依赖。可使用当前获准的本地分析工具；此入口不启动实验、不读取未获准的研究目录。
