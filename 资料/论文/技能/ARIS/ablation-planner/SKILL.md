# 论断驱动的消融计划

本入口是中文方法适配；英文入口与它等义，二者均不是上游全文直译。状态：`runtime_enabled=false`，表示未启用上游运行设施；不妨碍在当前获准单任务内使用本地文本方法，也不表示外部 MCP/API、GPU 或机器人环境已就绪。只读写当前任务明确范围，不继承上游自动权限、固定模型或无限 review；不自动上传、发通知、定时、租 GPU 或扫描作者 home。实际证据、独立审查和未验证状态分别记录。

## 输入

当前方法的可移除或可替换组件、基线差别、真实主要结果、已支持或部分支持的论断，以及本次获准的计算预算。

## 方法

1. 先逐条对应机制论断与现有证据；主要结果尚未建立时写缺口，避免用大量消融掩盖主实验失败。
2. 设计移除组件、以更简单方案替换组件的对照，先隔离新增机制；与基线完全相同的组件不安排无效消融。
3. 为每项明确“检验什么”与“组件起作用时预期看到什么”，再列关键超参数敏感性和自然设计选择对照。
4. 记录必须跑与可选项、代码改动还是配置改动、先后依赖与成本估计；优先信息量大的组件消融和配置改动，不把成本估计写成实际耗时。
5. 对超过预算的清单提出有理由的删减，保留删减记录。获准执行时先做小样检查，再记录所有正负结果，按结果修订论断。

## 产物与验收

消融矩阵：变体、对应论断、可区分预测、控制条件、优先级、运行顺序和预算；验收时每项都能回答一个机制问题，已有数值能回到真实结果文件，未跑项标为计划。
