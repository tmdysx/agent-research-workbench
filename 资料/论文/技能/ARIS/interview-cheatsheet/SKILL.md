# 专题教程与面试速查

本入口为方法适配，并非逐字全文翻译。完整上游原文单独保留。材料和产物写当前获准工作区，先读本轮目标、计划、适用戒律和最新接手记录。

## 输入

明确技术主题、读者基础、篇幅及真实代码环境.

## 方法

1. 先定主题边界和结构，从直觉、公式推导到实现、变体、复杂度和易错点。
2. 关键公式列假设与推导，示例代码只有真运行后才记通过。
3. 按必会、进阶、深入研究三个层次组织问题与答案，不用固定字数代替教学完整。
4. 核公式/代码/来源并保留审查来源；HTML渲染或跨模型检查未运行明确标未完成。

## 产物与验收

专题教程、分层问答、可运行示例与实际核验表.

每项结论和完成状态能回到实际文件、来源及检查。缺材料、缺独立环境或未执行检查明确报告；产物已写不代替平台交付验收。
