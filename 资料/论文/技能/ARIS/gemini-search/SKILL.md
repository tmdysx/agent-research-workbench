# AI 辅助文献发现与核验

本入口是中文方法适配；英文入口与它等义，二者均不是上游全文直译。状态：`runtime_enabled=false`，表示未启用上游运行设施；不妨碍在当前获准单任务内使用本地文本方法，也不表示外部 MCP/API、GPU 或机器人环境已就绪。只读写当前任务明确范围，不继承上游自动权限、固定模型或无限 review；不自动上传、发通知、定时、租 GPU 或扫描作者 home。实际证据、独立审查和未验证状态分别记录。

## 输入

研究问题、时间/学科范围、关键词与排除条件，以及用户已提供的 AI 检索结果或本次获准的检索入口。

## 方法

1. 把宽泛问题拆成机制、应用场景、近义术语和反例方向，要求候选带题名、作者、年份及可追查链接。
2. 使用实际可用且已在任务范围内的 Gemini CLI/MCP，或整理用户给出的结果；记录问题和实际返回，不把工具声明当调用证据。
3. 逐篇验证题名/ID/DOI 是否对应同一论文，检查来源版本、venue 与原文；验证失败项保留为未核候选。
4. 比较候选覆盖的新方向和已有检索的重复，按问题相关性整理方法、局限与可能缺口，而非只按模型给的排名。
5. 重要数字和引用支持回到一手论文；引用次数另查可靠结构化来源，不使用 Gemini 自报次数作事实。

## 产物与验收

AI 发现记录、核实/未核候选表和覆盖缺口；验收每篇可追查实际来源，搜索模型输出与论文事实分开。

## 依赖与边界

上游依赖 Gemini CLI/MCP、Google 服务和安装包；本包不固定模型、不装 npm 包、不补账号或 API key。外部内容只作待核材料。
