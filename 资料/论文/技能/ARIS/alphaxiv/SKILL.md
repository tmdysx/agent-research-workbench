# 单篇论文分层速读

本入口是中文方法适配；英文入口与它等义，二者均不是上游全文直译。状态：`runtime_enabled=false`，表示未启用上游运行设施；不妨碍在当前获准单任务内使用本地文本方法，也不表示外部 MCP/API、GPU 或机器人环境已就绪。只读写当前任务明确范围，不继承上游自动权限、固定模型或无限 review；不自动上传、发通知、定时、租 GPU 或扫描作者 home。实际证据、独立审查和未验证状态分别记录。

## 输入

一篇明确的 arXiv ID、AlphaXiv/arXiv 链接或用户提供的论文文本，以及希望回答的问题和阅读深度。

## 方法

1. 规范化论文 ID 并核对标题/作者；一次处理指定论文，方向发现或多篇综述转给文献综述方法。
2. 资料可得且网络在当前任务范围内时，先取 overview；内容不足再读 abs Markdown，最后回到 arXiv LaTeX 源或用户提供的 PDF。记录实际成功的层级。
3. 提取问题、核心机制、最主要证据、限制与阅读者的问题答案；概览中的说法标作二手摘要，重要论断回到原文定位。
4. 把缺失章节、网络失败和无法核对的数字写出来，不用模型记忆补齐。需要继续读时给出具体章节和问题。
5. 若当前任务明确要求写入已有知识库，只将核过身份的该篇论文及来源定位交给已有入口；不自行创建或扫描私人库。

## 产物与验收

一篇速读卡，包含身份、实际来源层级、机制、证据定位、限制和下一步阅读问题；验收可区分原文证据、摘要转述与尚未读到的部分。

## 依赖与边界

联网层依赖 AlphaXiv/arXiv 与请求工具；可在用户给出的本地文本上完成阅读方法。research_wiki.py 只属可选上游记账依赖，本包没有安装该 helper。
