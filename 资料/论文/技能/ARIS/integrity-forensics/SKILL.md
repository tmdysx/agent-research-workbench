# 诚信取证方法与义务表

本入口为方法适配，并非逐字全文翻译。完整上游原文单独保留。材料和产物写当前获准工作区，先读本轮目标、计划、适用戒律和最新接手记录。

## 输入

获准稿件、原始数据/统计记录、取证范围.

## 方法

1. 将待核论断锚定到稿件页段或字符位置，并列出可以复查的原始证据。
2. 仅在适用假设满足时做统计一致性核对，区分可复算异常、审查者建议和已证实问题。
3. 逐项登记问题、证据、修复责任和待复验义务；保留原问题，不能靠反复改稿磨到通过。
4. 原文Anti-Autoresearch固定版本launcher未内置；本地检查不得冒称46模式完整扫描、typed gate或上游评测通过。

## 产物与验收

位置证据账本、义务与复验表、实际检查范围和未执行项.

每项结论和完成状态能回到实际文件、来源及检查。缺材料、缺独立环境或未执行检查明确报告；产物已写不代替平台交付验收。
