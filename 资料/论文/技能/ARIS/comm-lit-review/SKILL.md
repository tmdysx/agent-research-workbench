# 通信领域分层文献综述

本入口是中文方法适配；英文入口与它等义，二者均不是上游全文直译。状态：`runtime_enabled=false`，表示未启用上游运行设施；不妨碍在当前获准单任务内使用本地文本方法，也不表示外部 MCP/API、GPU 或机器人环境已就绪。只读写当前任务明确范围，不继承上游自动权限、固定模型或无限 review；不自动上传、发通知、定时、租 GPU 或扫描作者 home。实际证据、独立审查和未验证状态分别记录。

## 输入

通信问题、系统层次与应用场景、时间/数据库范围、用户明确给出的文献集合和会议期刊限制。

## 方法

1. 先把问题定位到 PHY/MAC、网络、传输或系统层及无线、蜂窝、卫星/NTN、Wi-Fi 等场景，写清优化对象和约束。
2. 在明确给出的本地材料或获准 Zotero/Obsidian 集合中查已有论文；保留来源归属，再用外部一次文献补齐缺口。
3. 按通信领域数据库层次检索，每层先重点期刊会议再拓宽；高水平 venue 默认作排序参考，仅当用户明确“只要”时作硬筛选。
4. 逐篇记录场景、协议/信道假设、方法、对照、吞吐/时延/可靠性等指标和限制，分开理论、仿真与实测证据。
5. 综合相同问题下的机制差异、不可直接比较的设置和重复失败模式，形成有出处的研究缺口；博客或摘要只作检索线索。

## 产物与验收

通信文献矩阵与分层检索记录，列场景、证据类型、可比条件、争议和研究缺口；验收不会仅凭成功指标排名或将仿真当实测。

## 依赖与边界

Zotero/Obsidian MCP 是可选材料入口，网络检索依赖可用服务。缺少这些入口时可综述已给材料并报告覆盖缺口，不扫描作者 home 或真实论文库。
