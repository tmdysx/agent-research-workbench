# 开放学术元数据与引文关系查询

本入口是中文方法适配；英文入口与它等义，二者均不是上游全文直译。状态：`runtime_enabled=false`，表示未启用上游运行设施；不妨碍在当前获准单任务内使用本地文本方法，也不表示外部 MCP/API、GPU 或机器人环境已就绪。只读写当前任务明确范围，不继承上游自动权限、固定模型或无限 review；不自动上传、发通知、定时、租 GPU 或扫描作者 home。实际证据、独立审查和未验证状态分别记录。

## 输入

主题、论文 DOI/OpenAlex ID 或机构/作者范围，年份、类型、结果上限及关系问题。

## 方法

1. 确定查 works、作者/机构还是引用关系，把关键词和筛选条件写成可复查查询；同名机构或作者先做身份消歧。
2. 在线入口可用时获取结构化元数据，保留标题、DOI、年份、作者、机构、出版来源、开放获取和数据更新时间。
3. 用 DOI/明确标识去重，同一工作不同版本保留关联；缺失 funding、机构或 venue 字段不从模型常识补填。
4. 按问题整理被引/参考关系和主题/机构分布，注明采集时点与数据库覆盖；引用次数是数据库指标，不证明论文质量或论断支持。
5. 需要具体科学论据时回到论文原文；输出可供文献筛选的元数据表及数据覆盖限制。

## 产物与验收

含查询口径和时点的元数据/关系表、去重规则与缺失项；验收身份可追查、版本不混同、数据库指标与正文证据分开。
