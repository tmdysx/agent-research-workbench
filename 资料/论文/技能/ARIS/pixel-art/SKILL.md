# 像素SVG插画

本入口为方法适配，并非逐字全文翻译。完整上游原文单独保留。材料和产物写当前获准工作区，先读本轮目标、计划、适用戒律和最新接手记录。

## 输入

主题、用途、品牌风格、尺寸与授权素材.

## 方法

1. 确定主体和极简轮廓，选择有限色板与像素网格。
2. 用对齐网格的SVG形状表达层次，保留可编辑源码。
3. 实际打开核缩放、边缘、留白及文字，按作者反馈小幅迭代。
4. 标装饰插画用途，不承担科研数字或机制证据。
