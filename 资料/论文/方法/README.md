# 论文：新手先看

先让论断找到证据，再写正文；把引用身份、原文支持和数值一致性分别核实。稿件流畅不是科学结论已经通过。

- [论文证据卡](论文证据卡.md)：复制到获准工作目录后填写。
- [引用核验卡](引用核验卡.md)：复制到获准工作目录后填写。

从 [科研全流程](../../文献/方法/科研/README.md) 看自己现在在哪一步；相关执行技能：[文献与证据](../../../技能库/research-literature-evidence/SKILL.md) · [论文写作与引用](../../../技能库/research-manuscript-citations/SKILL.md)。也可让当前 agent 先读 [科研路线](../../../技能库/research-route/SKILL.md)。技能可直接读 Markdown，不要求额外模型 API 或特定宿主。

先填输入、来源、授权和预算，再由 agent 做事，最后打开真实产物验。未确定、待核、未运行和未验证按事实保留；不要为了填满模板编数字或完成状态。原始材料与失败记录留存，文件编号沿项目既有规则。

这些是科研版的业务载荷与原创模板，复制后才写实际研究；主要用于计算与机器学习，其他领域按其证据和协议调整。内置模板不放作者私有数据。本目录不会启动员工、发送邮件、上传或投稿。
