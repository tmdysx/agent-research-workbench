# Built-in PPT workspace

The workspace has only Materials and Results, reading `材料/` and `导出/` respectively. Materials offers the material-list template; Results has no template shortcut. All five existing blank templates remain in `工作台/模板/`. Materials → outline → slides → exports → checks remains the production method, not five page sections.

The two-area configuration, templates, methods and introductory PPTX/PDF in `工作台/作品/` are inherited by new projects. `入门示例.json` explicitly initializes these files into `导出/` for direct access from Results. Existing different files are preserved and reported as conflicts. The full earlier package and its assets remain in `作品/MiracleHarness项目介绍/`, preserving old links. Private materials, other presentations and check records stay local. This work does not publish the application.

Read `资料/PPT/技能/SKILL.en.md`. Canonical methods are in `技能库/业务/presentation/ppt-master/`. Web and MCP use the same revision-controlled files, history and operator records.

This contains methods, templates and the declared introduction package, not the full PPT Master program or its external assets. PPT remains a removable purple business module.
