# PPT工作台内置

工作台只有“素材 Materials”和“成果展示 Results”两区，分别读取 `材料/`、`导出/`。素材区可用材料清单模板，成果展示区不挂模板；五份旧空模板仍保留在 `工作台/模板/`。材料 → 大纲 → 幻灯片 → 导出 → 检查保留为制作方法流程，不再作为页面五区。

两区配置、空模板、方法与 `工作台/作品/` 中的介绍PPTX/PDF供新项目继承。`入门示例.json` 明确将这两个文件初始化到 `导出/` 根目录，工作台直接展示；内置原件保留。内容不同的已有作品保留并报告冲突。发行展示案例保存在上述工作台/作品和导出目录；作者工作目录不随包复制。项目自己的素材、其他演示、导出与检查记录不随新项目复制；本轮不执行发布。

技能入口在 `资料/PPT/技能/SKILL.md`，方法正本在 `技能库/业务/presentation/ppt-master/`。网页和MCP读写同一份文件；保存须用完整版本，旧文进入历史并记录操作者。

这里内置方法、模板与声明的介绍成品包，不安装PPT Master程序或其外部资产。PPT是可移除的紫色业务模块。
