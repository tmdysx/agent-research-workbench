# PPT业务：从材料到演示

先读项目目标、计划、适用戒律和最新交接。网页只有“素材 Materials”和“成果展示 Results”两区，分别读取 `材料/`、`导出/` 的普通文件。材料 → 大纲 → 幻灯片 → 导出 → 检查是制作方法流程，不是五个页面分区；缺工具或待确认材料明确记录。

[演示方法：中文](<../../../技能库/业务/presentation/ppt-master/SKILL.md>) · [English](<../../../技能库/业务/presentation/ppt-master/SKILL.en.md>)

制作前确定受众、主题、时长、输出格式及每页读者任务。页计划与真实数据分开保存；保留可编辑产物、讲者备注、逐页预览和实际打开结果。未制作或未打开不能写成通过。

工作台两区配置、原空模板与 `作品/MiracleHarness项目介绍/` 成品包保留供新项目继承；介绍PPTX/PDF在本项目 `导出/` 根目录直接展示，内置原件保留。当前项目自己的素材和其他导出不随新项目复制。以后经作者批准发布应用时随带内置介绍，不在本轮执行发布。

本模块内置文字方法与空模板，不自动运行上游脚本、调用模型、安装软件或发布。完整程序与外部资产分别核工具版本及许可。用现有P/J/H流程交付和接手。
