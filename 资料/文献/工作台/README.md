# 文献工作台

两个入口：**文献库**与**交互式下载**，默认打开文献库。论文、规范、教程和项目参考材料都可以从这里学习。

- **文献库**：在同一处管理原文、查看资料信息，并点开精读。原来的 L 编号、原文与解读关系保留。有想法就点右上角「羽毛笔加纸」便签；记下后在统一笔记本查看。
- **交互式下载**：粘贴链接或 DOI 添加条目；可以下载、选择 PDF 或把文件拖到条目上。状态来自实际文件。

起步示例使用作者自己的《MiracleHarness 项目介绍》PDF，配有简短讲解。下载列表另有 Transformer、GPT-3 和 ReAct 官方论文链接示例；第三方论文全文不附在发行包里。

网页和 agent 使用同一份本地记录。新项目带上内置示例，不带当前项目的其他论文、笔记和运行记录；不会替你生成读过、记过或验收过的记录。
