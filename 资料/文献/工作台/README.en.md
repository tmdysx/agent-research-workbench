# Literature workspace

Two entry points: **Library** and **Interactive downloads**, with Library opening by default. Use them to learn from papers, specifications, tutorials and project references.

- **Library**: manage originals, inspect metadata and open close reading in one place. Existing L identifiers and original-to-reading links remain intact. Use the feather-and-page button for a floating note; saved notes belong to the shared project notebook.
- **Interactive downloads**: add a URL or DOI, download a PDF, choose a local file or drop it on an entry. Status reflects actual files.

The starter example uses the author's own *MiracleHarness Project Introduction* PDF, with a short reading guide. Downloads also offers official Transformer, GPT-3 and ReAct paper links. Third-party paper PDFs are not bundled.

The webpage and agents share local records. New projects inherit built-in examples, not this project's other papers, personal notes or run history. The example does not mark anything as read, noted or accepted on your behalf.
