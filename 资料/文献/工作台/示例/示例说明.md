# 用项目介绍体验精读

> agent:codex 编写 · 2026-10-07。示例原文使用作者自己的《MiracleHarness 项目介绍》PDF。

文献模块默认打开「文献库」。点项目介绍进入精读，左边看 PDF，右边看简短讲解。需要记想法时，点右上角「羽毛笔加纸」便签；记下后在平台统一笔记本查看。示例不预填你的便签、批注或已读状态。

「交互式下载」是另一入口：粘贴链接或 DOI 可以添加，选择条目可以下载、补入本地 PDF、查看状态和打开原文。新建项目预置 Transformer、GPT-3 和 ReAct 三个官方论文链接，不自动下载；获取论文后才显示下好了。

项目介绍 PDF 作为内置示例随新项目带上。其他论文只带官方链接，当前项目自己的论文、笔记和运行记录不跟随。
