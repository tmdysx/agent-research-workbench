# 文献模块的技能

> 模块专属技能，放在模块里：`资料/文献/技能/SKILL.md`（作者 09-28：「这个模块要有自己的skill」「模块专属技能就放模块里吧」）。
> 先读这份，再读这个模块的戒律 `治理/戒律/模块/文献.md`（必须守的）和 `资料/文献/格式说明.md`（每个文件长什么样）。这份只讲**怎么做**；规矩以戒律为准。

## 这个模块是什么

一个轻量的「小绿鲸 + Zotero」：人在网页上读论文、记笔记、画批注、管文献；**翻译、速读、补信息、答疑、图解交给 agent**。

网页只保留两个入口：**下载列表**和**文献库**，默认文献库。列表可添加链接、触发下载或上传 PDF，状态来自真实文件；文献库同页管理原文与精读，不拆成重复页面。文件目录默认收起，旧链接仍可打开。

新项目按 `工作台/入门示例.json` 带作者自己的项目介绍 PDF 与简短讲解，以及三条官方论文下载链接。初始化不下载第三方全文，不写人的笔记，不改变阅读状态；重复执行保留已有内容。一般阅读 GET 不初始化示例。

```
资料/文献/
├── 原文/            原版 PDF（L1 标题.pdf），不改不删不搬（文-1）
├── 解读/L1 标题/    这一篇的一切解释：信息.json · 批注.json · 文本/ · 图片/ · 图解/
├── 下载清单.md      要下的论文，一篇一行（下-n）
├── 格式说明.md      （需求、施工单、戒律 09-30 起集中在 治理/：需求/文献.md · 任务/文献.md · 戒律/模块/文献.md）
└── 技能/SKILL.md    这份
```

## 论文从哪来：学校付费的正版

- **下载的论文都是学校付了钱的**（作者 09-28：「只要是下载的都是我们学校付钱了的，都是学校交了钱有版权的」）：学校订了出版社的数据库，人用学校账号下，是合法取得的正版。
- 所以要登录学校账号才能下的，照样排进下载清单（`add_download`），**人用学校账号去下**；你自己不下、不找别的地方下。
- 学校买的是**使用授权**，版权还是出版社和作者的：只在这台电脑上个人学习研究用——不传到外网、不进 git、新项目不带（文-5、文-8）。
- 来源只认：学校订的数据库、出版社官网、arXiv、开放获取。不用盗版站，不绕付费墙（文-9）。

## 入库：程序做，你不用动手

- 人把 PDF 拖进文献库页，或者下载清单下好了，程序自己编 L 号（号不回收）、改名、建好 `解读/L… 标题/`（三格 + 信息.json），第一页读得出 DOI 就填上。
- 下载清单那一行写了作者 · 年 · 期刊的，入库时自动带进 `信息.json`。
- 你要做的是**补信息**：`信息.json` 里写「查不到」的字段去查（标题、作者、年份、期刊、卷期页、DOI）；查不到就留「查不到」，不编；DOI 写之前在 doi.org 打开过（文-6）；写上 `"补信息": "agent:你的名字 · 日期"`。

## 写解读：放 `解读/L… 标题/文本/`，一份一个 .md

- **按页分段**：`## 第 3 页`，下面可以再分 `### ¶2`（第几段）。阅读页左边翻到第几页，右边就滚到那一段——不按页分就跟不上。
- **开头一行写谁写的**：`> agent:claude-code 写 · 2026-09-28`（文-3）。
- 几种文件（名字固定，网页按这个顺序排）：
  - `讲解.md`：用自己的话讲每一页在说什么、为什么，名词解释、读的时候要注意的地方。自己推出来的结论标「（agent 自己推的，不是论文原话）」
  - `速读.md`：六个要点——背景、问题、方法、结果、结论、局限
  - `译文.md`：照 文-4 的格式——按页、按段对着原文，不漏句子、不改意思，拿不准的术语后面标「（？）」
- **注意**：claude-code 自己的规矩是不把有版权的文章整篇复述出来（逐句翻成中文也算），所以它写讲解、速读，不写逐句全译；译文用什么做，人来定。
- 公式照论文的记号写（`$…$`）；图和表不整张抄，讲它说明了什么。

## 便签、笔记本与 PDF 批注

- 作者 2026-10-06/07 确认“统一笔记”“文献不需要专属的笔记本”。精读工具条、右上角与全屏的羽毛笔加一页纸按钮，都打开平台原有的浮动便签；记下后在平台笔记本查看。左侧叠书图标是笔记本，二者不要混用。
- 便签可带文献编号、原文路径、页码和选句，沿用人的草稿、附件、记下与复制流程。agent 读取平台笔记里的来源后继续工作；别改删人的记录。
- `文本/笔记.md` 和 `文本/.笔记历史.md` 是旧记录，保持原文，可从文件入口阅读；不再自动新增专属笔记或迁移旧内容。
- 高亮、PDF 贴纸和笔画仍在 `批注.json`，网页管理，别手改。界面把 PDF 定位批注叫“贴纸”，与浮动便签区分；旧数据中的 kind="便签" 保持兼容。

## 边读边问：人问你的，先答

- 选中原句点“问 agent”，问题进入平台问答，来源保留文献编号、页码和原句。
- 用 `answer_person(问-编号, 答案)` 回答，写清依据；没读到的直说，不编。
- 答案保存在问答，提问操作进入日志，不再自动写入专属笔记或冒充人写入笔记本。人决定哪些内容放进便签。

## 找论文：排进下载清单，不自己下

- `add_download(title, url 或 doi, why, module="文献", authors, year, venue, note)`：
  - `why` 写为了哪条需求、哪件事；作者写前两个，多的写「等」；知道就写，有 DOI 的程序会去 OpenAlex 补
  - `note` 写要注意的，比如「是书，不必下 PDF」「软件手册：到官网取引用格式」
- 清单按出版社分组（从 DOI 认），每组一句去哪下；每篇写着「存成」什么名字——人照这个名字存进 `原文/`，程序就认得是哪一篇。
- 排进去以后先做不依赖它的事；下好了 `get_overview` 里那篇就不在「还没下好」里了。

## 图解：`解读/L… 标题/图解/`，一个原理一页

- 一页自包含的 `.html`，只从 `/lib/` 加载库（three、katex、mermaid，文件在 `工具库/下载/`），不联网（文-7）。
- 数字用论文里的；示意的写明「示意」；页面里写清依据第几页第几段。

## 装修这个模块（施工）

- 需求在 `治理/需求/文献.md`（只有人改），要做的几件在 `治理/任务/文献.md`（`| S2-n | 做什么 | 为了 | 怎么验 | 状态 |`）。做一件先看它为了哪条需求、怎么验。
- 交付：`deliver(goal="文献", sub="S2-n", …)`，填写真实检查。当前项目按作者启用的 `checks-pass` 策略，检查全部通过后由交付接口标记完成并接续；失败返工，人发现不对时也可打回。不能直接改状态冒充完成。
- 用到的工具：T10 pdf.js（阅读页）· T11 pdfminer.six（抽标题、DOI）· T12 KaTeX · T13 Mermaid · T14 Three.js（图解）。
- 改后台、网页这些核心之前先存一档全量（`save_checkpoint`），改完用 MCP `add_log` 记一条「改了核心」；机器操作归日志，人的字归笔记。
