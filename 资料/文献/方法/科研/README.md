# 从选题到投稿：先看这页
科研版已内置九个中文技能。你不用读代码，先写方向、材料、期限、资源，agent 按每阶段步骤干，你按产物验。

1. 选题：我想回答什么？得到选题卡、近似工作和可反驳预测。
2. 文献：别人已经做什么？得到查询记录与原文可定位证据。
3. 设计：怎样比较才公平？得到数据划分、基线、评价和预算。
4. 运行：确实跑了吗？得到版本命令、原始日志和真实结果。
5. 分析：结果支持到哪里？得到可复算表图、局限和负结果。
6. 写作：每句话有依据吗？得到论文、引用和一致性核验。
7. 投稿准备：材料符合哪套要求？得到本地包及作者确认清单。
8. 返修：意见都回应了吗？得到逐条回复、修改位置和补实验证据。

总入口“科研路线”帮你判断现在到哪，不要求从头重做已有工作。综述和理论研究有各自分支，不捏造实验；本包主要用于计算/机器学习研究，其他领域须采用领域协议。

把下面指令交给正在使用的 agent：
> 先读 AGENTS.md 和技能库/research-route/SKILL.md，按我授权的材料写路线卡，找出当前阶段并完成下一件事。别编数字、别读私人库、别直接投稿或发布。

[安装与九个技能入口](安装与使用.md) · [改编与未内置范围](改编与未内置清单.md) · [来源与原许可](来源/阅读说明.md)

选题模板在 [想法模块的科研模板](../../../想法/方法/科研/选题卡.md)，复制后填；每个技能 assets 另有对应模板。
模板里的未确定、待核、未运行就是还没完成，不要假装填满。
阅读技能不需额外模型 API、收费服务或运行框架；真实验按需用已有 Python 环境，文献与期刊政策查询可用浏览器/公开来源。
本包不会启动新 agent、自动上传或投稿。研究是否足以发表由证据、作者和期刊决定，不由流程图保证。
