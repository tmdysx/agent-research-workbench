# 科研内置包：安装与使用
本包是从选题到投稿返修的中文做法，给人看模板、给 agent 执行步骤，不保证研究成功或录用。

## 本地安装
科研版已把九个技能目录放根技能库，第三方固定原文与许可在资料/文献/方法/科研/来源。解压科研版直接读，不需装上游框架/插件/模型 SDK；纯通用版不含这九个目录。
若从通用版加装，只复制清单中的九个技能目录、资料/文献/内置/科研及资料/想法/内置/科研目录；同名目录已有则先保留旧版对比，不覆盖人的文件。不复制 build-tools 或整个暂存目录。

## 如何开始
打开科研路线的 assets/路线卡.md，写题目、已有材料、期限、资源和权限，不懂写未确定。交给当前 agent：
> 先读项目 AGENTS.md 和技能库/research-route/SKILL.md。按我指定材料制作路线卡，找当前阶段并在授权内完成下一件事。无证据数字别写，不能直接投稿或公开上传。
宿主不自动发现技能时直接读取文件和文内 references；无需模型 API key。文件读取是保底用法，不绑定宿主插件机制。

## 技能目录
| 技能 | 何时用 | 入口 |
|---|---|---|
| 科研路线 | 识别科研任务当前阶段，制定从选题到投稿返修的路线、预算和交接；用于小白开始项目或换 agent 接手。 | [打开技能](../../../../技能库/research-route/SKILL.md) |
| 选题与假设 | 将研究兴趣或观察变成有证据边界、可反驳预测和可行性说明的选题；用于开题，不把候选假设当发现。 | [打开技能](../../../../技能库/research-topic/SKILL.md) |
| 文献与证据 | 建立检索记录、文献比较和论断证据表；用于综述、研究缺口与论文论据，区分来源存在和真正支持论断。 | [打开技能](../../../../技能库/research-literature-evidence/SKILL.md) |
| 数据与实验设计 | 把论断转成有数据权限、无泄漏划分、公平基线、评价指标和预算的实验方案；主要用于计算与机器学习研究。 | [打开技能](../../../../技能库/research-experiment-design/SKILL.md) |
| 复现与运行 | 在获准资源内复现基线和执行计算实验，保存命令、版本、原始结果及失败；不启动平台模型或租资源。 | [打开技能](../../../../技能库/research-reproduce-run/SKILL.md) |
| 结果分析与图表 | 从真实实验结果计算比较与可追溯图表，判定论断范围；用于结果、消融和失败分析，不编数据。 | [打开技能](../../../../技能库/research-results-figures/SKILL.md) |
| 论文写作与引用 | 依据真实方法结果与定位文献组织论文并核引用和数值；用于草稿修订，不编实验、作者声明或批准。 | [打开技能](../../../../技能库/research-manuscript-citations/SKILL.md) |
| 投稿准备 | 查目标期刊当前官方要求，制作本地投稿包和声明缺口清单；不登录、上传、付款或自动提交。 | [打开技能](../../../../技能库/research-submission-package/SKILL.md) |
| 返修与回复 | 把本稿审稿意见逐条映射到修改、补实验、正文位置和有据回复；保留原意见，不自动发送。 | [打开技能](../../../../技能库/research-revision/SKILL.md) |

模板在各 assets，复制到本次授权业务目录填写。待核、未提供、未运行是状态，不能填虚构事实。

## 模块与依赖
文献证据归文献，设计/运行/结果归实验，稿件投稿返修归论文，图表及来源归素材，报告归汇报。可按用户选择另建选题 Research Questions、投稿 Submission 业务模块；本包不自动改模块或写死后端。
读技能和填模板无脚本依赖。真计算/绘图用已有或明确选择的 Python 环境，按需选包，不默认装一整库；查询文献/当前期刊政策需网络或获准来源。导出用宿主已有工具，本包无上游可执行助手。
主要适用计算/机器学习；综述理论调整分支，真实医学/动物/湿实验另需领域协议。现有登录 agent 按其宿主模型服务运行，无新增 API key 不等于全部离线处理。
