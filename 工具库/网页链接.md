# 网页链接

> 常用的权威网站，一组一张表；工具页「网页链接」那一块照这里列，点了在新标签打开。
> 加一个：在对应的组里加一行「名字 · 网址 · 干什么用」；要新的组就加一个 `## 组名` 和一张表。网址写完整（https:// 开头）。
> 作者 10-01：「工具模块还要加一个网页链接」「你看看要加一些啥权威的网站比较合适？」——下面是第一批，用不上的删掉、缺的照着加。

## 找论文

| 名字 | 网址 | 干什么用 |
|---|---|---|
| Google Scholar | https://scholar.google.com | 什么领域的论文都搜，看被引次数、谁引了它 |
| Semantic Scholar | https://www.semanticscholar.org | 免费的学术搜索，带摘要、引用关系、相关论文 |
| arXiv | https://arxiv.org | 计算机、数学、物理的预印本，最新的工作先在这出来 |
| DBLP | https://dblp.org | 计算机领域的论文目录：会议、期刊、作者，查得准 |
| OpenAlex | https://openalex.org | 开放的学术数据库：论文、作者、期刊；下载清单查合法免费版就用它 |
| PubMed | https://pubmed.ncbi.nlm.nih.gov | 医学、生命科学的论文 |
| 中国知网 CNKI | https://www.cnki.net | 中文期刊、学位论文、会议 |
| 万方数据 | https://www.wanfangdata.com.cn | 中文期刊、学位论文 |
| IEEE Xplore | https://ieeexplore.ieee.org | IEEE 的期刊和会议论文 |
| ACM Digital Library | https://dl.acm.org | ACM 的期刊和会议论文 |
| ScienceDirect | https://www.sciencedirect.com | Elsevier 的期刊（学校买了的能下全文） |
| SpringerLink | https://link.springer.com | Springer 的期刊和书 |

## 查期刊和引用

| 名字 | 网址 | 干什么用 |
|---|---|---|
| DOI | https://doi.org | 输 DOI 跳到论文的正式页面 |
| Crossref | https://search.crossref.org | 查论文的 DOI、正式题目、发表信息 |
| Web of Science | https://www.webofscience.com | 引文数据库（要学校买的权限） |
| Scopus | https://www.scopus.com | 引文数据库、期刊指标（要学校买的权限） |
| 中科院期刊分区表 | https://www.fenqubiao.com | 查期刊在中科院分区里是几区 |
| Retraction Watch 撤稿库 | https://retractiondatabase.org | 引之前查一下那篇有没有被撤稿 |
