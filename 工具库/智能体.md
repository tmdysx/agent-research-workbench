# 智能体

> 市面上的 AI 智能体（agent），分美国、中国两组；工具页「Agent」那一块照这里列，查这台电脑装了哪些。
> 作者 10-01：「你把市面上所有中国和美国的智能体都加上」。10-01 逐个打开核过官网：跳到新地址的已经改成新的；OpenAI、Perplexity、Grok 挡脚本（403），浏览器里能开。这是 2026 年中的了解，产品改名、下架、出新的很快——**以官网为准**，过时的改这一行、新的照着加一行。
> 各列：**什么样**（命令行 / 编辑器 / 编辑器插件 / 桌面 / 网页 / 手机）· **接本应用**（能 = 支持 MCP，照工具页给的那段配置就能接上这个应用；不能 = 没有 MCP 或只在云端；要查 = 没把握）·
> **命令**（装了在命令行里叫什么，用来查装没装）· **Windows 位置**（桌面程序装在哪，`%LOCALAPPDATA%` 这种写法）· **官网**。
