# 随带网页库 · 安装与使用

PDF、公式、图表、Office 阅读和终端所需网页资源已经随包。

> 不需要为了阅读文件安装 Node、Office 或每一个网页库；缺文件才修复。

![随带网页库准备流程](../图示/bundled-web-libraries.svg)

## 什么时候需要

了解项目随带能力，或检查文件预览报资源缺失。不是让你一次下载所有库。

## 输入、调用与输出

输入：授权的 PDF、DOCX、XLSX、公式或图表。调用：本机网页按功能读取随包资源。输出：页面显示；这里不提供 Office 文件编辑器，也不执行模型任务。

## 官网与下载入口

- [官方入口](https://github.com/mozilla/pdf.js)
- [下载或官方安装说明](https://registry.npmjs.org/pdfjs-dist)

## Windows 与安装位置

既有位置是工具库/下载的指定库目录，程序按这些路径读取。保留原 LICENSE；不要把所有外部软件下载到内置目录。

本页面向 Windows 桌面；其他系统请选官网对应发行并按其说明操作，本项目未在本轮宣称跨系统实测。

## 操作步骤

1. 先检查下面资源文件是否存在。齐全就无需安装。

2. 从应用启动后打开授权的公开样例文件，验证实际阅读；不要直接双击模板.html 代替后台。

3. 缺资源先确认拿到的项目完整，查下载清单（`工具库/下载/清单.md`）中的版本和指纹。

4. 确需补齐时由有授权的人或 agent 按指定官方版本恢复到相同路径，保留许可证；不随手升级最新版。

## 安装授权与调用范围

用户自己运行下面的安装命令前，确认安装对象、位置、来源与许可。agent 只有得到对应安装授权才能执行；已有明确授权可引用原记录。安装软件、启用插件、允许自动开工是三件不同的事。指南不会自动下载安装、登录、启用插件或启动员工。可执行软件不放入必须复制的内置资料。

## 怎么检查成功

下面是给你操作的命令说明，本次写文档没有实际执行安装。带示例目录的命令先替换真实路径；项目相对路径命令在项目根执行。

```powershell
$webResources = @('工具库/下载/pdfjs/pdf.min.mjs', '工具库/下载/pdfjs/pdf.worker.min.mjs', '工具库/下载/katex/katex.min.js', '工具库/下载/mermaid/mermaid.min.js', '工具库/下载/three/three.module.js', '工具库/下载/sheetjs/xlsx.full.min.js', '工具库/下载/docx-preview/docx-preview.min.js', '工具库/下载/jszip/jszip.min.js', '工具库/下载/xterm/xterm.js')
$webResources | ForEach-Object { [pscustomobject]@{ 文件 = $_; 存在 = Test-Path -LiteralPath $_ } }
```

文件检查各行显示 True，网页实际打开所需格式成功。存在仅证明文件齐全，不代表所有浏览器和全部文件格式都已验收。

## 失败时怎样处理

- PDF 空白：同时检查 worker 文件，查看浏览器真实报错；扫描 PDF 无文字不等于阅读引擎缺失。

- Word/Excel 读取失败：保留原文件，区分资源 404、文件损坏和格式不支持。

- 只有公式字体缺失：核对 KaTeX fonts 和 CSS，不重装整个工作台。

## 各库负责什么

| 资源 | 用途 | 已随带的位置 |
|---|---|---|
| pdf.js | PDF 页面与文字 | 工具库/下载/pdfjs/ |
| KaTeX | 数学公式排版 | 工具库/下载/katex/ |
| Mermaid | 流程图 | 工具库/下载/mermaid/ |
| Three.js | 浏览器三维显示 | 工具库/下载/three/ |
| SheetJS | Excel 读取 | 工具库/下载/sheetjs/ |
| docx-preview、JSZip | Word 页面读取 | 工具库/下载/docx-preview/、jszip/ |
| xterm.js、addon-fit | 网页终端显示 | 工具库/下载/xterm/ |

浏览器由用户自备。前端是原生 HTML/JavaScript，不要求 node_modules 或构建步骤。完整来源与原许可见 下载清单（`工具库/下载/清单.md`） 和 根目录的 `第三方许可证.md`。
