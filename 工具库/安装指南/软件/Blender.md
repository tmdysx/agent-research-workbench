输入：获准模型、参考图和建模脚本。调用：桌面 Blender 或明确授权的后台脚本。输出：新版本 .blend、GLB 与渲染图；原手改模型保留。

## Windows 与安装位置

可用官方 Windows Portable ZIP，完整解压到非内置工具目录。历史项目曾在工具库/下载/Blender 使用便携版本；新用户没有这个历史软件，指南不复制作者程序和个人配置。

本页面向 Windows 桌面；其他系统请选官网对应发行并按其说明操作，本项目未在本轮宣称跨系统实测。

## 操作步骤

1. 现在只阅读本页，不开始世界树任务。需要安装时先确定版本、Windows 架构、设备要求和安装授权。

2. 从官方下载入口选择稳定发行的 Windows Portable ZIP 或安装版；本文不把 dev 手册版本称为推荐稳定版。

3. 完整解压到非内置工具目录；安装版的系统关联和 PATH 由用户选择。记录 blender.exe 的真实路径。

4. 经授权后，先查版本，再在新的示例目录保存/重开一个空场景；正式模型和脚本按施工计划处理。

## 安装授权与调用范围

用户自己运行下面的安装命令前，确认安装对象、位置、来源与许可。agent 只有得到对应安装授权才能执行；已有明确授权可引用原记录。安装软件、启用插件、允许自动开工是三件不同的事。指南不会自动下载安装、登录、启用插件或启动员工。可执行软件不放入必须复制的内置资料。

## 怎么检查成功

下面是给你操作的命令说明，本次写文档没有实际执行安装。带示例目录的命令先替换真实路径；项目相对路径命令在项目根执行。

```powershell
& 'D:/Tools/Blender/blender.exe' --version
```

在你实际安装的软件上得到版本；需要时才做新场景保存验证。本轮没有执行这条安装检查，也没有恢复世界树施工。

## 失败时怎样处理

- 指南中的 D:/Tools 只是示例：替换真实路径，不以作者机器路径判断自己是否安装。

- 设备无法运行：查所选稳定版官方需求，不乱降级、不安装未知显卡驱动。

- 失败或历史文件存在：不覆盖手工模型，保留错误与输入，等待当前三维任务授权。
