# Cursor · 安装与使用

可选桌面编程客户端；按系统架构安装并打开当前项目。

> 桌面客户端可接文件和 MCP；未宣称现有自动运行器支持 Cursor 员工。

![Cursor准备流程](../图示/cursor.svg)

## 什么时候需要

用户喜欢用桌面编辑器与 agent 一起工作时；不用换掉自己的现有工具。

## 输入、调用与输出

输入：当前项目文件夹、规矩与任务。调用：Cursor 中获准 agent。输出：项目修改与记录；账号和模型由 Cursor 提供。

## 官网与下载入口

- [官方入口](https://cursor.com/)
- [下载或官方安装说明](https://cursor.com/download)

## Windows 与安装位置

官网下载页可选 Windows User/System 与 x64/ARM64；位置和管理员要求由选项决定。程序和用户配置不放入项目内置。

本页面向 Windows 桌面；其他系统请选官网对应发行并按其说明操作，本项目未在本轮宣称跨系统实测。

## 操作步骤

1. 在官方 Download 页选择对应架构；只供自己使用可以看 User 版，不照抄作者架构。

2. 运行安装器，按自己的安装范围选择位置。

3. 启动后在 Help/About 核版本，按客户端要求登录；打开本项目根文件夹。

4. 让 agent 先读 AGENTS.md；MCP 采用客户端当前官方配置方式，填实际 Python、项目路径和员工名。

5. 做只读目标检查。平台中的可读文件/MCP 接入能力与自动启动能力分开确认。

## 安装授权与调用范围

用户自己运行下面的安装命令前，确认安装对象、位置、来源与许可。agent 只有得到对应安装授权才能执行；已有明确授权可引用原记录。安装软件、启用插件、允许自动开工是三件不同的事。指南不会自动下载安装、登录、启用插件或启动员工。可执行软件不放入必须复制的内置资料。

## 怎么检查成功

下面是给你操作的命令说明，本次写文档没有实际执行安装。带示例目录的命令先替换真实路径；项目相对路径命令在项目根执行。

```powershell
Get-Command cursor -ErrorAction SilentlyContinue | Select-Object Name,Source
```

应用可启动、关于页可见版本、当前文件夹正确；MCP 读出的项目一致。CLI 路径缺失不代表桌面未装。

## 失败时怎样处理

- 应用能开但命令不存在：用应用内版本检查，按官方命令行配置需要再补。

- MCP 红灯：检查完整路径和 Python 依赖；不把其他客户端的 JSON 原样照搬。

- 模型不可用：保留实际提示，由用户处理账户，不能把已安装当已可施工。
