# Git · 安装与使用

读取改动和保存本地版本；不自动上传或发布。

> 安装 Git 不等于登录 GitHub；本指南不含 push 或发布。

![Git准备流程](../图示/git.svg)

## 什么时候需要

要使用本地版本历史、差异和后续工作树能力时；只阅读普通文件不必先学 Git。

## 输入、调用与输出

输入：当前项目文件。调用：版本检查、status、diff。输出：本地差异与版本记录。写提交、恢复或建立工作树按任务授权执行。

## Windows 与安装位置

官方安装版可装系统或自选目录；Portable 可解压到非内置工具目录。个人用户名、邮箱和凭据不写进模板。

本页面向 Windows 桌面；其他系统请选官网对应发行并按其说明操作，本项目未在本轮宣称跨系统实测。

## 操作步骤

1. 打开官方 Windows 安装页，按 x64／ARM64 选择 Setup；要便携版则选 Portable。

2. 运行安装器或解压到自选位置。若要从 PowerShell 使用，安装器里选择相应命令路径选项。

3. 新开 PowerShell，检查版本与实际路径。

4. 在项目根用只读命令查看状态。项目没有 .git 时，提示非仓库并不等于 Git 安装失败；不要自行初始化或上传。

## 安装授权与调用范围

用户自己运行下面的安装命令前，确认安装对象、位置、来源与许可。agent 只有得到对应安装授权才能执行；已有明确授权可引用原记录。安装软件、启用插件、允许自动开工是三件不同的事。指南不会自动下载安装、登录、启用插件或启动员工。可执行软件不放入必须复制的内置资料。

## 怎么检查成功

下面是给你操作的命令说明，本次写文档没有实际执行安装。带示例目录的命令先替换真实路径；项目相对路径命令在项目根执行。

```powershell
git --version
Get-Command git -ErrorAction SilentlyContinue | Select-Object Source
git -c core.quotepath=false status --short
git diff --stat
```

版本和路径可读；在确有 Git 的项目中能查看状态。未提交改动不是安装失败。

## 失败时怎样处理

- 找不到命令：重开终端或用 git.exe 完整路径。

- 要求设置姓名/邮箱：这是提交身份设置，由用户填写，不复制作者身份。

- 不要用 reset --hard、clean 或覆盖还原解决安装问题。
