# 网页终端 · 安装与使用

在自动化页面看本机真实终端，先检查依赖再由人启用。

> 仅 Windows 插件；xterm 已随包，另需后台同一 Python 的 pywinpty 3.0.3。

![网页终端准备流程](../图示/web-terminal.svg)

## 什么时候需要

需要自动化页的真实 PowerShell 窗口。空终端出现不代表真实 agent 已登录或接通。

## 输入、调用与输出

输入：人的终端操作或获准员工任务。调用：网页终端插件中的本机 shell/真实 CLI。输出：终端状态和员工记录；关网页不等于停止终端进程。

## 官网与下载入口

- [官方入口](https://pypi.org/project/pywinpty/3.0.3/)
- [下载或官方安装说明](https://pypi.org/project/pywinpty/3.0.3/)

## Windows 与安装位置

插件文件已在插件/网页终端；xterm 随包在工具库/下载/xterm。pywinpty 装入启动后台的同一个 Python，不放入内置资料，也不需要新装 Node。

本页面向 Windows 桌面；其他系统请选官网对应发行并按其说明操作，本项目未在本轮宣称跨系统实测。

## 操作步骤

1. 先按[后台依赖](后台依赖.md)核对解释器。确保下面 python 与实际后台解释器相同；隔离环境用完整路径替换。

2. 先看已有 pywinpty 版本。缺固定 3.0.3 时，在授权后从 PyPI 安装 wheel；没有可用 wheel 就记录架构/解释器缺项，不自动安装 Rust 或编译工具。

3. 检查随带 xterm 三个文件，齐全不重下；详细固定包与许可见插件正本 `插件/网页终端/插件.md`。

4. 运行插件 check.py。通过后由人在工具页检查和启用，再到自动化窗口打开空终端。

5. 实际员工另按客户端指南登录、配置岗位/范围/身份；先读当前 MCP 目标，自动开工仍由人控制。

## 安装授权与调用范围

用户自己运行下面的安装命令前，确认安装对象、位置、来源与许可。agent 只有得到对应安装授权才能执行；已有明确授权可引用原记录。安装软件、启用插件、允许自动开工是三件不同的事。指南不会自动下载安装、登录、启用插件或启动员工。可执行软件不放入必须复制的内置资料。

## 怎么检查成功

下面是给你操作的命令说明，本次写文档没有实际执行安装。带示例目录的命令先替换真实路径；项目相对路径命令在项目根执行。

```powershell
python -c "import sys; print(sys.executable)"
python -m pip show pywinpty
python -m pip install --index-url https://pypi.org/simple/ --only-binary=:all: pywinpty==3.0.3
python -c "import importlib.metadata as m; print(m.version('pywinpty'))"
python -X utf8 -B 插件/网页终端/check.py
```

pywinpty 为 3.0.3，check.py 退出正常；启用后本机终端能收发输入。真实 agent 是否能登录、读 MCP 必须另验。

## 失败时怎样处理

- 没有匹配 wheel：核对 Windows 架构与 Python，记录缺项，不擅自换固定版本。

- xterm 文件缺失：按插件正本固定版本恢复资源和许可证，不装完整 Node 工程。

- 终端或员工不运行：分别检查插件、CLI、账户、项目路径和开工许可；不能用“允许开工”冒充“在干活”。
