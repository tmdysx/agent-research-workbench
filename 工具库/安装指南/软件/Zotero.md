# Zotero · 安装与使用

管理文献与书目信息；桌面应用和浏览器 Connector 分别准备。

> 可选文献工具；本项目不会读取你的私人 Zotero 库。

![Zotero准备流程](../图示/zotero.svg)

## 什么时候需要

希望管理文献、保存网页书目信息或处理引用时。用其他管理器也可将授权 PDF/书目交给文献模块。

## 输入、调用与输出

输入：用户选择的公开书目、授权 PDF 或网页。调用：Zotero 与对应浏览器 Connector。输出：个人库中的条目/附件，按授权导出的 BibTeX/RIS/PDF；不会自动同步整库到项目。

## 官网与下载入口

- [官方入口](https://www.zotero.org/)
- [下载或官方安装说明](https://www.zotero.org/download/)

## Windows 与安装位置

桌面应用按安装器选择用户或系统位置。文献数据目录由用户单独管理；程序和私人库都不放内置、不随模板复制。

本页面向 Windows 桌面；其他系统请选官网对应发行并按其说明操作，本项目未在本轮宣称跨系统实测。

## 操作步骤

1. 打开官方 Downloads，选择 Windows 与实际架构的桌面应用；官网下载页也提供不同系统版本。

2. 运行桌面安装程序并启动；到帮助里的版本信息确认已打开正确应用。

3. 回到同一官方页，为实际浏览器安装 Connector。扩展安装与权限提示由用户确认。

4. 用一条公开示例文献测试“通过标识符添加”或网页保存，核对标题、作者、年份；按本项目授权只导出选中的条目。

## 安装授权与调用范围

用户自己运行下面的安装命令前，确认安装对象、位置、来源与许可。agent 只有得到对应安装授权才能执行；已有明确授权可引用原记录。安装软件、启用插件、允许自动开工是三件不同的事。指南不会自动下载安装、登录、启用插件或启动员工。可执行软件不放入必须复制的内置资料。

## 怎么检查成功

下面是给你操作的命令说明，本次写文档没有实际执行安装。带示例目录的命令先替换真实路径；项目相对路径命令在项目根执行。

```powershell
Get-Command zotero -ErrorAction SilentlyContinue | Select-Object Name,Source
```

桌面应用能打开，帮助/关于可见版本，Connector 能保存选中的公开条目。上面命令找不到不代表未安装：GUI 应用可能不在 PATH，必须按实际启动核验。

## 失败时怎样处理

- Connector 存不进桌面库：确认桌面应用在运行、扩展启用，并读官方故障说明。

- 条目元数据不完整：对照原文核验，不把自动提取当可信事实。

- 不要为排错删除私人库或关闭全部安全设置；同步、存储付费和账号由用户自己决定。
