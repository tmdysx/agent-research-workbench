# Claude Code · 安装与使用

可选终端 agent；自己安装登录，再接项目记录。

> 保留原员工历史；本页不会启用 Claude 员工，也不承诺账号配额。

![Claude Code准备流程](../图示/claude-code.svg)

## 什么时候需要

用户自己选择 Claude Code 时；当前项目默认接管安排不因这份指南改变。

## 输入、调用与输出

输入：项目规矩与获准任务。调用：真实 Claude Code。输出：获准文件和记录。账号、网络与模型权限由该客户端提供。

## 官网与下载入口

- [官方入口](https://code.claude.com/docs/en/setup)
- [下载或官方安装说明](https://code.claude.com/docs/en/setup)

## Windows 与安装位置

按官方原生安装方式安装到本机用户位置；不复制客户端或账号文件进内置。Windows 原生方式可运行 PowerShell；官方现行文档将 Git Bash 作为可选。

本页面向 Windows 桌面；其他系统请选官网对应发行并按其说明操作，本项目未在本轮宣称跨系统实测。

## 操作步骤

1. 确认官方系统要求与实际地区/账号可用性，打开官方安装页。

2. 按当前官方 Windows 方式安装。下方示例使用官方列出的 WinGet 包；没有 WinGet 可按官方原生安装步骤，不为此下载未知安装器。

3. 新开终端检查 claude 版本，在项目根运行 claude，并由用户自行完成登录和条款提示。

4. 读本项目 CLAUDE.md / AGENTS.md，再按官方 MCP 说明与[Agent接入](../Agent接入.md)填当前项目和员工身份。

## 安装授权与调用范围

用户自己运行下面的安装命令前，确认安装对象、位置、来源与许可。agent 只有得到对应安装授权才能执行；已有明确授权可引用原记录。安装软件、启用插件、允许自动开工是三件不同的事。指南不会自动下载安装、登录、启用插件或启动员工。可执行软件不放入必须复制的内置资料。

## 怎么检查成功

下面是给你操作的命令说明，本次写文档没有实际执行安装。带示例目录的命令先替换真实路径；项目相对路径命令在项目根执行。

```powershell
winget --version
winget install Anthropic.ClaudeCode
claude --version
claude
```

版本可见、真实客户端登录成功、读取到当前项目；MCP 项目和身份一致。安装成功不等于已授权自动运行。

## 失败时怎样处理

- 没有 winget：改看官方原生安装说明，不复制 CMD 语法到 PowerShell。

- 找不到 claude：重开终端并按官方 PATH 故障说明核对。

- 额度/登录不可用：记真实缺项；不换身份、不搬作者认证。
