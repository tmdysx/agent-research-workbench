# 剪辑 · 安装与使用

现有 FFmpeg 协议和命令卡；网页剪辑器还没有完成。

> 当前只有协议/命令卡；检测到 FFmpeg 不代表网页剪辑器已实现。

![剪辑准备流程](../图示/media-edit.svg)

## 什么时候需要

获准 agent 要对视频做截段、拼接、去声、截图或字幕。只看视频时继续用现有视频预览。

## 输入、调用与输出

输入：明确授权的原视频、时间段、字幕与预期格式。调用：FFmpeg 命令卡。输出：临时目录中先验的成品，成功后到资料/素材/剪辑并附剪辑记录；原文件只读。

## 官网与下载入口

- [官方入口](https://ffmpeg.org/)
- [下载或官方安装说明](https://ffmpeg.org/download.html)

## Windows 与安装位置

命令卡随插件；FFmpeg 另在非内置工具目录准备，详见[FFmpeg](FFmpeg.md)。此页不装程序，不将 GPL 构建带进项目。

本页面向 Windows 桌面；其他系统请选官网对应发行并按其说明操作，本项目未在本轮宣称跨系统实测。

## 操作步骤

1. 阅读插件正本 `插件/剪辑/插件.md`，明确当前网页尚未完成，不寻找不存在的剪辑按钮。

2. 按 FFmpeg 指南检查版本与所需滤镜；只有新的安装授权才补程序。

3. 明确输入授权、起止时间、允许输出位置和新文件名。运行时保留 -n，输入输出不能同路径。

4. 先在索引/剪辑临时生成输出并核对画面、声音、时长；成功后按项目协议放素材目录，附真实命令与版本记录。

5. 交付前检查用户原话；没有跑出的数字和画面不写成通过。

## 安装授权与调用范围

用户自己运行下面的安装命令前，确认安装对象、位置、来源与许可。agent 只有得到对应安装授权才能执行；已有明确授权可引用原记录。安装软件、启用插件、允许自动开工是三件不同的事。指南不会自动下载安装、登录、启用插件或启动员工。可执行软件不放入必须复制的内置资料。

## 怎么检查成功

下面是给你操作的命令说明，本次写文档没有实际执行安装。带示例目录的命令先替换真实路径；项目相对路径命令在项目根执行。

```powershell
ffmpeg -version
ffprobe -version
ffmpeg -hide_banner -filters | Select-String 'subtitles|drawtext|drawbox'
```

记录程序真实状态；一次获准剪辑的产物内容满足任务要求。不能用这些检查宣布网页剪辑页已完成。

## 失败时怎样处理

- 滤镜缺失：按 FFmpeg 指南记录构建缺项。

- 中文字幕/Windows 滤镜路径错误：用协议的相对输入方式和实际报错修正，不改原视频。

- 成品重名或半成品：换新文件名并保留失败记录，不覆盖或把未完成输出混进成品。
