# 后台依赖 · 安装与使用

按同一个 Python 准备后台、文件读取与测试依赖。

> 统一按项目 requirements 准备；不需要逐个安装数据库或前端构建器。

![后台依赖准备流程](../图示/backend-dependencies.svg)

## 什么时候需要

Python 已准备好，但第一次启动或报缺少模块；程序升级改变 requirements 时先阅读差异，不盲目升级。

## 输入、调用与输出

输入：项目自带 backend/requirements.txt。调用：同一解释器的 `-m pip`。输出：该 Python 环境中的包、检查记录；依赖不是项目业务材料。

## 官网与下载入口

- [官方入口](https://pip.pypa.io/)
- [下载或官方安装说明](https://pypi.org/)

## Windows 与安装位置

简单用法可装到既有专用 Python。需要隔离时，在非内置工具目录创建单独环境；项目里的 `工具库/环境/工作台` 是一种位置选择。此环境不属于必须复制的内置资料。

本页面向 Windows 桌面；其他系统请选官网对应发行并按其说明操作，本项目未在本轮宣称跨系统实测。

## 操作步骤

1. 在文件资源管理器打开项目根目录，在地址栏输入 powershell 并回车；提示符当前位置应是含 backend 的文件夹。

2. 先执行 Python 指南的路径检查。确认后，安装当前 requirements；没有明确安装授权时，agent 只给步骤，由你运行。

3. 按下面命令检查依赖并启动。网页地址以终端实际输出为准，不把作者电脑端口硬写成所有人的端口。

4. 需要隔离环境时用本页下方的可选方案；不要一边给全局 Python 装包，一边用另一环境启动。

5. 接入 MCP 时用启动后台的那个 Python 的绝对路径。

## 安装授权与调用范围

用户自己运行下面的安装命令前，确认安装对象、位置、来源与许可。agent 只有得到对应安装授权才能执行；已有明确授权可引用原记录。安装软件、启用插件、允许自动开工是三件不同的事。指南不会自动下载安装、登录、启用插件或启动员工。可执行软件不放入必须复制的内置资料。

## 怎么检查成功

下面是给你操作的命令说明，本次写文档没有实际执行安装。带示例目录的命令先替换真实路径；项目相对路径命令在项目根执行。

```powershell
python -c "import sys; print(sys.executable)"
python -m pip install -r backend/requirements.txt
python -m pip check
python -c "import fastapi, uvicorn, websockets, mcp, pptx, pdfminer, sqlite3; print('后台依赖可导入'); print(sqlite3.sqlite_version)"
python -X utf8 backend/main.py
```

pip check 无依赖冲突、导入检查通过、终端给出本机网页地址且浏览器能打开。依赖检查与真实启动要分别记结果。

## 失败时怎样处理

- 缺 pip：按 Python 官方说明修复该解释器的 pip，不执行环境不明的裸 pip。

- ModuleNotFoundError：核对装包和启动的 sys.executable 是否相同。

- 下载超时或版本冲突：保存 pip 原报错与 requirements，不偷偷升级整台电脑或删环境。端口占用时查看实际提示，不关闭别人的服务。

## 可选：单独的工作台环境

在项目根执行前确认基础 Python 已可用。环境目录若已经存在，应复用并检查，不覆盖。

```powershell
python -m venv 工具库/环境/工作台
& './工具库/环境/工作台/Scripts/python.exe' -m pip install -r backend/requirements.txt
& './工具库/环境/工作台/Scripts/python.exe' -m pip check
& './工具库/环境/工作台/Scripts/python.exe' -X utf8 backend/main.py
```

**双击启动.bat 不保证使用这个环境**：现有启动器优先找全局 Python312。使用隔离环境时明确运行环境内的 python.exe，MCP 填它的绝对路径；不要仅凭“已激活”判断。

## 依赖分工

FastAPI、uvicorn、websockets 负责本机后台与连接；MCP 负责 agent 接口；python-pptx 负责 PPT 文字与图片读取；pdfminer.six 负责 PDF 文本。SQLite 随 Python 提供，不装独立数据库。pytest、httpx 用于程序验证，目前也在 requirements 中。python-docx、openpyxl 是 agent 制作 Office 时的可选环境依赖，**不在当前后台 requirements**。
