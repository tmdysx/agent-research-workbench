# Codex · 安装与使用

选择桌面或 CLI，登录自己的账号，再绑定本项目 MCP。

> 网页员工需要真实可调用 CLI；桌面登录和安装不自动等于 CLI 检查通过。

![Codex准备流程](../图示/codex.svg)

## 什么时候需要

选 Codex 做本地任务或现有自动化的真实员工。只使用工作台本身时不必先安装 agent。

## 输入、调用与输出

输入：AGENTS.md、明确任务和授权范围。调用：用户所选真实 Codex 客户端。输出：文件、MCP 记录和交接；模型运行与配额由用户账号提供。

## 官网与下载入口

- [官方入口](https://learn.chatgpt.com/docs/cli)
- [下载或官方安装说明](https://learn.chatgpt.com/docs/quickstart)

## Windows 与安装位置

桌面版按官方当前入口安装；CLI 可用 npm 或官方现有方式。客户端和账号凭据保留本机，不装入项目内置。平台本机设置可填写真实 codex 可执行文件位置。

本页面向 Windows 桌面；其他系统请选官网对应发行并按其说明操作，本项目未在本轮宣称跨系统实测。

## 操作步骤

1. 打开官方入门，选择桌面或 CLI。需要网页终端员工时，必须另外确认真实 CLI 可以运行；不要只看桌面窗口。

2. 选择 npm 时先按[Node.js](Node.js.md)准备环境，再使用下方官方安装命令；已有可用 CLI 则先检查，不自动升级。

3. 新开终端查版本，再在当前项目根启动 codex。首次按官方提示选择 Sign in with ChatGPT；账号是否可用由实际登录和运行决定，本指南不要求另申请模型 API。

4. 读 AGENTS.md，然后按[Agent接入](../Agent接入.md)配置 stdio MCP；比较网页、MCP 的项目名称和员工身份。

5. 先做读取项目目标的检查；要自动开工先由人定岗位、范围与开工许可，不替用户启动员工。

## 安装授权与调用范围

用户自己运行下面的安装命令前，确认安装对象、位置、来源与许可。agent 只有得到对应安装授权才能执行；已有明确授权可引用原记录。安装软件、启用插件、允许自动开工是三件不同的事。指南不会自动下载安装、登录、启用插件或启动员工。可执行软件不放入必须复制的内置资料。

## 怎么检查成功

下面是给你操作的命令说明，本次写文档没有实际执行安装。带示例目录的命令先替换真实路径；项目相对路径命令在项目根执行。

```powershell
node --version
npm.cmd --version
npm.cmd install -g @openai/codex@latest
codex --version
codex
```

CLI 版本可读，在正确项目可登录，MCP 能返回该项目的目标和技能。没有配额、权限或模型时记录实际原因，不能称为已连通。

## 失败时怎样处理

- npm 命令找不到：先检查 Node；已有桌面随带 CLI 可用时不强装第二套。

- 桌面可用而 codex 命令找不到：核对真实可执行文件并按本机设置配置，不复制作者完整路径。

- 登录或配额失败：用户自行处理账号；不复制认证文件、不把账户状态伪装成成功。
