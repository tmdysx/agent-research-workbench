# draw.io · 安装与使用

制作流程和架构图，保存可编辑源文件并导出图片。

> 本地桌面版可用；不假定用户已经安装作者的 drawio-sci 技能。

![draw.io准备流程](../图示/drawio.svg)

## 什么时候需要

需要流程图、架构图或可编辑的论文示意图。平台中的 Mermaid 可满足简单图时可先不安装。

## 输入、调用与输出

输入：获准 .drawio 文件或新的示例图。调用：桌面软件或明确路径的导出命令。输出：.drawio 源文件和新的 PNG/SVG/PDF，旧源文件保留。

- [官方入口](https://github.com/jgraph/drawio-desktop)
- [下载或官方安装说明](https://github.com/jgraph/drawio-desktop/releases)

## Windows 与安装位置

可在官方发行页选择 No Installer ZIP，解压到非内置工具目录；安装版位置由用户选择。把实际 draw.io.exe 目录记在本机工具路径，不复制作者路径。

本页面向 Windows 桌面；其他系统请选官网对应发行并按其说明操作，本项目未在本轮宣称跨系统实测。

## 操作步骤

1. 打开官方维护仓库的 Releases，选择 Windows Installer 或 No Installer ZIP，核对当前发行的适用架构。

2. 安装或完整解压到选择的位置，不只拷贝单个 exe。

3. 打开软件，新建一个两个方框的示例图并保存为示例.drawio。

4. 用“文件 → 导出”导出 PNG，确认源图可以重开；需要 agent 自动导出时先确定 exe 完整路径和输入输出范围。

## 安装授权与调用范围

用户自己运行下面的安装命令前，确认安装对象、位置、来源与许可。agent 只有得到对应安装授权才能执行；已有明确授权可引用原记录。安装软件、启用插件、允许自动开工是三件不同的事。指南不会自动下载安装、登录、启用插件或启动员工。可执行软件不放入必须复制的内置资料。

## 怎么检查成功

下面是给你操作的命令说明，本次写文档没有实际执行安装。带示例目录的命令先替换真实路径；项目相对路径命令在项目根执行。

```powershell
& 'D:/Tools/draw.io/draw.io.exe' --version
```

版本命令给出正常输出，示例可保存、重开并导出。上面 D:/Tools 是位置示例，必须替换。

## 失败时怎样处理

- 命令行找不到 draw.io：填实际 exe 完整路径，不因此重复安装。

- ZIP 解压后无法启动：检查是否完整解压和架构匹配。

- 导出失败保留报错，最多按任务协议修正后再试；不覆盖源图或无限重试。
