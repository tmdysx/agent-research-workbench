# 国内与国外安装方案

先选一个实际要用的软件，再选下载入口。国内方案优先厂商中文站和明确来源的维护方镜像；国外方案优先官方发行。**这里区分软件下载、账号登录、模型服务三件事**，没有承诺所有网络或账号都可用。

## 镜像怎样用

- Python、Node.js、Git for Windows、TeX Live/CTAN、LibreOffice、Blender 可选择清华大学 TUNA 已核对的目录；发行许可仍归原软件。
- 后台依赖、JupyterLab、pywinpty 的 pip 命令可对本次增加 `-i https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple`。
- npm CLI 包可对本次选择 `--registry=https://registry.npmmirror.com`；没有核到当前清华 npm 服务，不把 Node 二进制镜像写成 npm 包源。
- 未核到中国独立发行渠道的 draw.io、Zotero、FFmpeg、Cursor 保留原官方入口；不填未经确认的网盘或代理地址。
- 这些方案不执行全局配置改写；同一软件主指南、网页入口与 agent 读取内容来自同一普通文件。

## Agent 选择与服务区别

国内可先看 TRAE CN、阿里云通义灵码、腾讯 WorkBuddy/CodeBuddy、智谱 ZCode、DeepSeek Harness 与阶跃桌面伙伴的官方入口。当前自动运行器支持范围没有因为增加指南扩大：MCP 官方能力、项目实连和自动启动适配分别核验。

Codex、Claude 等包可下载不代表模型服务对所有地区开放；国内方案按官方支持地区明确说明。DeepSeek 官方 Web UI 当前需模型 API key；ZCode 官方支持 BigModel/Z.ai 账号套餐登录。阶跃桌面的外部 stdio MCP 入口未核到，不套用 API 平台介绍。

软件安装位置用户自选，内置只保留知识、图示和出处。世界树施工仍暂停；Blender 只写未来参考步骤。本轮没有下载安装程序、登录账号、启用插件或代人开工。
