# 随带网页库 · 国外安装方案

网页阅读资源已随包，通常无需重新下载或安装。

![随带网页库准备图](../图示/bundled-web-libraries.svg)

## 下载和安装来源

- [官方软件 / 项目入口](https://github.com/mozilla/pdf.js)
- [本方案下载 / 安装说明](https://registry.npmjs.org/pdfjs-dist)
- [完整安装、用途与排查指南](../%E8%BD%AF%E4%BB%B6/%E9%9A%8F%E5%B8%A6%E7%BD%91%E9%A1%B5%E5%BA%93.md)

本地随带方案：两地区均使用模板内已有网页资源，不需要账号或远程 CDN 才能读本地文件。

软件程序不放内置，位置由用户选择；当前实例可放非内置工具目录，不能让新项目复制整个安装环境。国内镜像是可选来源，下载来源、软件原发行者、模型服务是不同对象。

## 按顺序操作

1. 先启动工作台，用自己授权的样例打开 PDF/图表/Office 文件。

2. 发现缺文件时核对主指南中的本地资源清单和第三方许可路径。

3. 只有实际缺失才按官方各库来源恢复到明确资源位置；本轮没有代用户更新打包库。

## 账号、模型和服务地区

本地随带阅读库无需模型登录。官方原库下载站是否可达与本地阅读能力是两回事。

## 核对真实结果

资源文件真实存在，授权样例可读；没有自动推出 Node、Office 已安装。

以下命令仅作说明，写文档时没有执行安装、登录、启用或启动。先读命令注释和主指南；有占位路径时替换为自己真实值。安装命令只给本次选择来源，不写全局 pip/npm 配置。

```powershell
Test-Path "工具库/下载/清单.md"
```

## 下载或运行失败

1. 记录失败的具体地址、步骤、时间与完整报错，先确认系统架构、版本和解释器。
2. 镜像缺包或不同步时对照原官方发行；没有核到国内独立渠道的条目保留官方入口，不猜代理站和网盘。
3. 账号、配额、地区限制归模型服务，包下载成功不能替代服务检查；[国内 / 国外方案总览](../国内与国外方案.md)提供另一入口。
4. 无当前安装检查适配时显示未检查；没有实际 MCP 连接结果也不补成已连通。当前授权不足的动作依项目原有流程记录待决定。
