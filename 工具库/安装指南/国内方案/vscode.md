# Visual Studio Code · 国内安装方案

国内方案仍使用微软官方 Windows 分发；目前未核到独立官方国内镜像，不提供未知网盘或代理安装包。软件下载、扩展市场与模型服务分别检查，不能保证全国网络可达。

## 入口与选择

- [微软官网下载](https://code.visualstudio.com/Download)
- [Windows 官方安装说明](https://code.visualstudio.com/docs/setup/windows)
- [完整用途、安装与检查](../开发工具/vscode.md)

普通单人优先 User Installer，按 Windows 系统类型选 x64 / ARM64，软件放非内置用户目录。ZIP 便携版自行更新；全机 System Installer 需要相应权限。

## 按顺序操作

1. 先查已有安装，避免重复装不同版本；官网选 Windows 正式发行与准确架构。
2. 下载并运行微软安装器，PATH 与文件关联按本人需要选择，保留安装目录。
3. 重新开终端检查 `code --version` 和 `Get-Command code`；打开自己的项目根并读 AGENTS.md。
4. 按需要分别准备 Python、C/C++ 编译器及 agent 扩展；扩展与模型账号不是编辑器下载附带的能力。

## 账号与网络

本地核心编辑器可独立使用；Microsoft 登录、Copilot 或其他 AI 服务须按当前产品条款另行确认。编辑器官方下载分发、Marketplace 与模型认证域名不同，某一个能访问不代表另两个已通。

```powershell
code --version
Get-Command code
```

以上仅是核对命令，不会下载安装。本文编写时没有试装、登录、改 PATH 或验证本机编辑器。

## 失败时处理与来源

命令不存在先重开终端或使用实际可执行路径。下载失败记录完整报错与地址，读[微软网络说明](https://code.visualstudio.com/docs/setup/network)，由用户按自己的网络规则处理；不禁用证书验证。没有确定的国内官方渠道时保留官方入口，另一入口见[国外方案](../全球方案/vscode.md)。

核验日期：2026-10-05。官方下载、Windows 说明、网络说明已只读核对；未实测各地网络或扩展认证。产品许可、标识与界面示例来源见[主指南](../开发工具/vscode.md)。

## 本页的执行范围

这是安装与检查说明，编写时没有安装软件、登录账号、启用插件或启动员工。软件程序放在非内置的工具目录或用户安装目录，例如 `工具库/软件/`；内置只带说明和识别图片。用户可自己按步骤安装；agent 执行安装时须引用对应授权，记录实际来源、版本和路径。
