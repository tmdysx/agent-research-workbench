# 从拿到文件到开始项目

![本地工作台示意](../../品牌/miracleharness2-terminal.png)

品牌插画表现用途，不是安装截图。详细步骤统一在这份内置安装指南中，从[从这里开始](从这里开始.md)进入，工具网页与 agent 读取同一份文件。

| 当前要做什么 | 去哪里 |
|---|---|
| 先打开本机工作台 | [Python](软件/Python.md)、[后台依赖](软件/后台依赖.md) |
| 查看已随带的阅读资源 | [随带网页库](软件/随带网页库.md) |
| 让真实 agent 读写项目 | [Agent接入](Agent接入.md) |
| 在自动化页用终端 | [网页终端](软件/网页终端.md) |
| 看 PPT 原版 | [PPT预览](软件/PPT预览.md)、[LibreOffice](软件/LibreOffice.md) |
| 文献或 Notebook | [Zotero](软件/Zotero.md)、[JupyterLab](软件/JupyterLab.md) |
| 制图与排版 | [draw.io](软件/draw.io.md)、[LaTeX](软件/LaTeX.md) |
| agent 剪视频 | [FFmpeg](软件/FFmpeg.md)、[现有剪辑协议](软件/剪辑插件.md) |

内置存指南和图示，软件安装目录保持非内置。先确认当前用途，不要求全部安装。软件与个人数据按各自许可使用，本页没有执行下载、安装或启用。
