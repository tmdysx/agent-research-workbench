# 从这里开始

拿到项目后，先让工作台在本机打开，再根据当前任务选择工具。安装指南、图示和来源已经内置；大软件、账号与个人环境不会随新项目复制。

![安装路线](图示/安装路线.svg)

## 第一次使用

1. 查看[Python](软件/Python.md)，检查这台电脑已有的解释器；没有时按官方来源准备。
2. 查看[后台依赖](软件/后台依赖.md)，用同一解释器准备依赖并打开本机网页。
3. [随带网页库](软件/随带网页库.md)已经在项目中，不需要逐项安装；打开自己的授权样例检查。
4. 需要 agent 干活时，自选一个已可用客户端，再看[Agent接入](Agent接入.md)。要网页终端再准备其插件；新模板不会因阅读指南自动开工。

## 安装到哪里

**内置放知识，非内置工具目录放程序。** 指南、图示和普通 catalog.json 是项目自带内容，普通文件就能读。Blender、FFmpeg、Node 等程序由用户按官方选择位置；不要把整个安装目录放进内置，避免下一个新项目把大软件复制出去。

用户自己安装时检查来源、架构、实际位置和许可。agent 安装须引用对应授权；启用插件、允许自动开工仍由人控制。平台不会要求你一次装完所有工具，不复制私人账户、文献库、科研数据或作者员工档案。

## 怎么分辨状态

- **已检查可用**：来自真实检查的对象和结果；程序版本存在还要按任务验证功能。
- **缺项**：记录具体缺什么、哪个环境，按对应指南恢复。
- **未检查**：没有相应工具卡或实跑结果；不能猜成已安装或未安装。
- **随带资源**：网页库已经随包，核对文件即可；不等于外部软件已装。
- **只有协议**：剪辑现有说明可供 agent 使用，但网页剪辑器未完成。

LibreOffice 的状态独立核验：PPT预览检查通过可能使用 PowerPoint，不能因此写 LibreOffice 已安装。世界树施工仍暂停；Blender 只提供之后可参考的指南。

## 图示与来源

图示为本项目自绘流程，不是安装器截图；品牌图是用途插画。官方标识原样下载并保存了[图片来源与使用条件](应用图片/来源.md)，不会把软件的开源许可直接当作 Logo 许可。每份指南有官方入口、步骤、检测命令和核验日期。版本、按钮与安装器变化时以官方实际页面为准；没有在本轮实际安装的，不写成实测成功。
