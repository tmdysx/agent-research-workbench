# T9 网页（一个 HTML 文件）

## 用在哪

- `模板.html`：三条导航、各个页面、笔记窗，全在这一个文件里；后台开着时由 T5 送给浏览器
- `技能库/网页前端/参考/模板.html` 是它的副本，改完同步

## 为什么选

- 不用构建、没有 node_modules：改完刷新就生效，作者和 AI 都能直接改
- 原计划的 React + TypeScript 没用上，要不要换看 `资料/蓝图/待你定.md` 第 6 条

## 改动注意

- 界面风格属于核心：改了在笔记本记一条「改了核心」（戒律 通-12）
- 导航的三条铁律别破（戒律 源-4）；只做电脑宽度（项-1）
